## Python Öğrenme Kaynakları Özeti

> **Translated to Turkish by** himmetcanumutlu

Pek çok arkadaş internette Python ile ilgili öğrenme kaynakları arıyor; ancak internetteki kaynakların kalitesi değişken; bazı sözde çok beğenilen içerikler, gerçekten öğrenme ihtiyacı olan insanlara aslında yardımcı olamıyor. Burada, sizler için kaliteli öğrenme kaynaklarını bir araya getiriyorum; daha az yanlış yola sapmanızı sağlamak istiyorum; umarım bu içerik size yardımcı olur.

> **Sıcak hatırlatma**: Aşağıda listelenen kaynaklardan kendinize uygun olanı seçmeniz yeterlidir; her biri öğrenmeye ve incelemeye değer değildir.

### Python Başvuru Kitapları

#### Giriş Seviyesi Okumalar

1. 《Python Programlama: Başlangıçtan Uygulamaya》（*Python Crash Course*）- ünlü piton kitabı, önerilir
2. 《Python Temel Eğitimi》（*Beginning Python From Novice to Professional*）- giriş klasiği
3. 《Python Öğrenme El Kitabı》（*Learning Python*）- ünlü fare kitabı
4. 《Python Programlamaya Giriş》（*Introduction to computation and programming using Python*）- bu kitabı ben çok seviyorum

#### İleri Düzey Okumalar

1. 《Python Cookbook》- tarife uyarak yaparsan kesin yanılmazsın; ileri düzey için ilk tercih
2. 《Akıcı Python》（*Fluent Python*）- usta olmanın zorunlu yolu
3. 《Effective Python: Kaliteli Python Kodu Yazmanın 59 Etkili Yolu》（*Effective Python 59 Specific Ways to Write Better Python*）
4. 《Python İleri Programlama》（*Expert Python Programming*）- ünlü çiçek kitabı
5. 《Python Proje Geliştirme Pratiği》- çok sayıda mühendislik projesi geliştirme bilgisi içerir

#### Veri Toplama

1. 《Python 3 Ağ Kazıyıcı Geliştirme Pratiği》- Cui Qingcai hocanın eseri - kişisel öneri
2. 《Python Ağ Veri Toplama》- ünlü pangolin kitabı

#### Veri Analizi

1. 《Python ile Veri Analizi》（*Python for Data Analysis*）- pandas'ın yazarının yazdığı kitap
2. 《Python Veri Bilimi El Kitabı》（*Python Data Science Handbook*）- O'Reilly hayvan serisinin iguana kitabı
3. 《Python Veri Analizi Pratiği》（*Python Data Analytics With Pandas, NumPy, and Matplotlib*）- kişisel öneri
4. 《Python Veri Görselleştirme Programlama Pratiği》（*Python Data Visualization Cookbook*）- odak noktası veri görselleştirme
5. 《Basitten İleriye Veri Bilimi》（*Principles of Data Science*）- bu kitabı ben çok seviyorum
6. 《Veri Bilimcileri İçin Pratik İstatistik》（*Practical Statistics for Data Scientists*）- çok pratik istatistik
7. 《Veri Bilimine Giriş》（*Data Science from Scratch*）

#### Makine Öğrenmesi

1. 《Makine Öğrenmesi Pratiği》（*Machine Learning in Action*）- giriş için önerilir
2. 《Makine Öğrenmesi (İris Matematik Serisi: Dört İşlemden Makine Öğrenmesine)》- Jiang Weisheng doktorun çok özenli eseri
3. 《Derin Öğrenmeye Giriş: Python Tabanlı Teori ve Uygulama》- Japonya'da ödüllü kitap, giriş için önerilir
4. 《Derin Öğrenme》（*Deep Learning*）- derin öğrenmenin klasik başyapıtı
5. 《Uygulamalı Derin Öğrenme》（*Dive into Deep Learning*）- Aston Zhang ve Li Mu'nun güçlü ortak eseri
6. 《Python Derin Öğrenme》（*Deep Learning with Python*）- bu kitabı ben çok seviyorum
7. 《Makine Öğrenmesi Pratiği》（*Hands-On Machine Learning with Scikit-Learn, Keras, and Tensorflow*）- ünlü kertenkele kitabı; makine öğrenmesinden derin öğrenmeye

#### Büyük Modeller

1. 《BERT Temel Eğitimi: Transformer Büyük Modeli Pratiği》（*Getting Started with Google BERT*）- beş yıldızlı kitap

2. 《Build a Large Language Model》
3. 《Hands-On Large Language Models》
4. 《Büyük Model Uygulama Geliştirmeye Minimal Giriş: GPT-4 ve ChatGPT Tabanlı》（*Developing Apps with GPT-4 and ChatGPT*）

#### Test ve İşletme

1. 《Selenium Otomasyon Testi: Python Dili Tabanlı》（*Learning Selenium Testing Tools with Python*）
2. 《pytest Test Pratiği》（*Python Testing with pytest*）
3. 《Python Otomasyon İşletme Pratiği》（*Hands-On Enterprise Automation with Python*）
4. 《Python Otomasyon İşletme Teknolojisi ve En İyi Uygulamaları》
