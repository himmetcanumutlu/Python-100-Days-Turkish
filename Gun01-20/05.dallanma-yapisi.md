## Dallanma Yapısı

> **Translated to Turkish by** himmetcanumutlu

Şimdiye kadar yazdığımız Python programları, deyimleri tek tek yukarıdan aşağıya sırayla çalıştırıyordu; bu kod yapısına **sıralı yapı** denir. Ancak yalnızca sıralı yapı her sorunu çözemez. Örneğin bir oyun tasarladığımızı düşünelim; oyunun birinci bölümünü geçme koşulu oyuncunun 1000 puan alması olsun. Birinci bölüm bittiğinde, oyuncunun aldığı puana göre ikinci bölüme geçmeye ya da oyuncuya "Game Over" (oyun bitti) demeye karar veririz. Bu senaryoda kodumuz iki dala ayrılır ve bunlardan yalnızca biri çalışır. Buna benzer birçok senaryo vardır; bu yapıya "dallanma yapısı" veya "seçim yapısı" diyoruz. Size bir dakika veriyorum; bu türden en az 5 örnek düşünebilirsiniz, hemen deneyin!

### if ve else ile Dallanma Yapısı Kurmak

Python'da dallanma yapısı kurmanın en yaygın yolu `if`, `elif` ve `else` anahtar sözcüklerini kullanmaktır. **Anahtar sözcük** (keyword), programlama dilinde özel anlamı olan kelimelerdir; elbette bunları değişken adı olarak kullanamazsınız. Tabii her dallanma yapısı kurduğumuzda üç anahtar sözcüğü birden kullanmayız; bunu örneklerle açıklayalım. Örneğin bir vücut kitle indeksi (BMI) hesaplayıcısı yazalım. Vücut kitle indeksi, aynı zamanda beden kitle indeksi olarak da bilinir; insan vücudunun şişmanlık/zayıflık derecesini ve sağlıklı olup olmadığını ölçmek için uluslararası alanda yaygın kullanılan bir göstergedir. Hesaplama formülü aşağıdaki gibidir. Genellikle $\small{18.5 \le BMI < 24}$ normal aralık, $\small{BMI < 18.5}$ zayıf, $\small{BMI \ge 24}$ kilolu, $\small{BMI \ge 27}$ ise obez kategorisine girer.

$$
BMI = \frac{kilo}{boy^{2}}
$$

> **Not**: Yukarıdaki formülde kilo kilogram (kg), boy ise metre (m) cinsindendir.

```python
"""
BMI hesaplayıcı

Version: 1.0
Author: 骆昊 (jackfrued)
"""
height = float(input('Boy (cm): '))
weight = float(input('Kilo (kg): '))
bmi = weight / (height / 100) ** 2
print(f'{bmi = :.1f}')
if 18.5 <= bmi < 24:
    print('Fiziğin harika!')
```

> **İpucu**: `if` deyiminin en sonunda bir `:` vardır; bu, İngilizce giriş modunda yazılan iki nokta üst üstedir. Programda girilen `'`, `"`, `=`, `(`, `)` gibi özel karakterler de İngilizce giriş modunda yazılmalıdır; bunu daha önce de hatırlatmıştık. Birçok yeni başlayan bu noktayı gözden kaçırır ve kodu çalıştırınca bir sürü hata mesajı görür. Elbette hata mesajlarını dikkatli okuyunca sorunun nerede olduğunu bulmak kolaydır, ama yine de **kesinlikle öneririz** ki kod yazarken **İngilizce giriş moduna geçin**; bu, birçok gereksiz sıkıntıyı önler.

Yukarıdaki kodda BMI hesaplayıp çıktı verdikten sonra bir dallanma yapısı ekledik. $\small{18.5 \le BMI < 24}$ koşulu sağlanırsa program "Fiziğin harika!" çıktısını verir; sağlanmazsa bu çıktı hiç görünmez. İşte az önce bahsettiğimiz gibi, kodun farklı yürütme yolları olabilir; bazı kodlar çalışmayabilir. `if` anahtar sözcüğünün ardına `18.5 <= bmi < 24` ifadesini koyduk; daha önce de söylediğimiz gibi, ilişkisel işlemler mantıksal değer üretir. `if`'ten sonraki mantıksal değer `True` ise, `if` deyiminin altındaki, dört boşlukla girintilenmiş `print('Fiziğin harika!')` çalışır. Önce birkaç veri grubu girip yukarıdaki kodu çalıştıralım; aşağıdaki gibidir.

Birinci girdi grubu:

```
Boy (cm): 175
Kilo (kg): 68
bmi = 22.2
Fiziğin harika!
```

İkinci girdi grubu:

```
Boy (cm): 175
Kilo (kg): 95
bmi = 31.0
```

Üçüncü girdi grubu:

```
Boy (cm): 175
Kilo (kg): 50
bmi = 16.3
```

Yalnızca birinci girdi grubundaki boy ve kilodan hesaplanan BMI, 18.5 ile 24 aralığında olduğu için `if` koşulu tetiklenir ve "Fiziğin harika!" çıktısı verilir. Şunu belirtmek gerekir: C, C++ ve Java gibi dillerden farklı olarak Python'da kod bloğu oluşturmak için süslü parantez kullanılmaz; **kodun hiyerarşisi girintileme (indentation) ile ifade edilir**. `if` koşulu sağlandığında birden çok deyim çalıştırmak gerekiyorsa, bu deyimlerin aynı girintiyi koruması yeterlidir. Başka bir deyişle, art arda gelen birkaç satır aynı girintiyi koruyorsa aynı **kod bloğuna** aittir; birlikte çalışan bir bütün gibi davranır. Girintileme için istenildiği kadar boşluk kullanılabilir ama **genellikle 4 boşluk** kullanılır; **kod girintilemek için sekme tuşunu (Tab) kullanmamanızı** kesinlikle öneririz. Zaten buna alıştıysanız, kod düzenleyicinizi 1 sekme tuşunu otomatik 4 boşluğa çevirecek şekilde ayarlayabilirsiniz; birçok düzenleyici bu özelliği destekler, PyCharm'da da varsayılan ayar budur. Ayrıca C, C++ ve Java gibi dillerde `18.5 <= bmi < 24` ifadesi `bmi >= 18.5` ve `bmi < 24` olmak üzere iki koşula ayrılıp "ve" operatörüyle bağlanır; Python'da bu şekilde de yapılabilir. Örneğin az önceki `if` deyimi `if bmi >= 18.5 and bmi < 24:` olarak da yazılabilir, ama gerek yok. `if 18.5 <= bmi < 24:` yazımı daha mı güzel değil? Aşağıda aynı işi Java koduyla yaptık; Java kodunu anlamasanız da olur, Python sözdizimiyle arasındaki farkı hissetmeniz yeterli.

```java
import java.util.Scanner;

class Test {

    public static void main(String[] args) {
        try (Scanner sc = new Scanner(System.in)) {
            System.out.print("Boy (cm): ");
            double height = sc.nextDouble();
            System.out.print("Kilo (kg): ");
            double weight = sc.nextDouble();
            double bmi = weight / Math.pow(height / 100, 2);
            System.out.printf("bmi = %.1f\n", bmi);
            if (bmi >= 18.5 && bmi < 24) {
                System.out.println("Fiziğin harika!");
            }
        }
    }
}
```

> **Not**: Yukarıdaki, BMI hesaplayıcının 1.0 sürümüne karşılık gelen Java kodudur. Birçok insanın Python'ı sevmesi boşuna değil; genellikle aynı sorunu daha az kodla çözer.

Şimdi yukarıdaki kodu biraz değiştirip, BMI $\small{18.5 \le BMI < 24}$ koşulunu sağlamadığında da uygun bir bilgi mesajı gösterelim. `if` kod bloğunun arkasına bir `else` kod bloğu ekleyebiliriz; `else`, `if`'teki koşul sağlanmadığında çalışır; aşağıdaki gibidir. Açıktır ki `if` altındaki `print('Fiziğin harika!')` ile `else` altındaki `print('Fiziğin pek ideal değil!')` deyimlerinden yalnızca biri çalışır.

```python
"""
BMI hesaplayıcı

Version: 1.1
Author: 骆昊 (jackfrued)
"""
height = float(input('Boy (cm): '))
weight = float(input('Kilo (kg): '))
bmi = weight / (height / 100) ** 2
print(f'{bmi = :.1f}')
if 18.5 <= bmi < 24:
    print('Fiziğin harika!')
else:
    print('Fiziğin pek ideal değil!')
```

Daha isabetli bilgi mesajı vermek istersek kodu tekrar değiştirip, `elif` anahtar sözcüğüyle dallanma yapısına daha fazla dal ekleyebiliriz; aşağıdaki gibidir.

```python
"""
BMI hesaplayıcı

Version: 1.2
Author: 骆昊 (jackfrued)
"""

print(f'{bmi = :.1f}')
if bmi < 18.5:
    print('Kilon çok düşük!')
```

### match ve case ile Dallanma Yapısı Kurmak

Python 3.10'da dallanma yapısı kurmanın yeni bir yolu eklendi: `match` ve `case` anahtar sözcüklerini kullanarak çoklu dallanma yapısını kolayca kurabiliriz. Python'ın resmî dokümantasyonu bu yeni sözdizimini tanıtırken, HTTP yanıt durum kodunu tanıma örneğini verir (HTTP yanıt durumuna göre karşılık gelen açıklamayı yazdırır); oldukça ilginçtir. HTTP yanıt durum kodunun ne olduğunu bilmiyorsanız MDN'deki [dokümana](https://developer.mozilla.org/en-US/docs/Web/HTTP/Status) bakabilirsiniz. Aşağıda resmî dokümandaki örneği biraz değiştirip bu sözdizimini anlatıyoruz; önce aşağıdaki `if-else` yapısıyla yazılmış koda bakın.

```python
status_code = int(input('Durum kodu: '))
if status_code == 400:
    description = 'Bad Request'
elif status_code == 401:
    description = 'Unauthorized'
elif status_code == 403:
    description = 'Forbidden'
elif status_code == 404:
    description = 'Not Found'
elif status_code == 405:
    description = 'Method Not Allowed'
elif status_code == 418:
    description = 'I am a teapot'
elif status_code == 429:
    description = 'Too many requests'
else:
    description = 'Unknown status Code'
print('Durum kodu açıklaması:', description)
```

Çalışma sonucu:

```
Durum kodu: 403
Durum kodu açıklaması: Forbidden
```

Aşağıda `match-case` sözdizimiyle yazılmış kod yer alır; işlevi tamamen aynı olsa da kod daha sade ve zarif görünür.

```python
status_code = int(input('Durum kodu: '))
match status_code:
    case 400: description = 'Bad Request'
    case 401: description = 'Unauthorized'
    case 403: description = 'Forbidden'
    case 404: description = 'Not Found'
    case 405: description = 'Method Not Allowed'
    case 418: description = 'I am a teapot'
    case 429: description = 'Too many requests'
    case _: description = 'Unknown Status Code'
print('Durum kodu açıklaması:', description)
```

> **Not**: İçinde `_` bulunan `case` deyimi kodda joker karakter (wildcard) görevi görür; önceki dallar eşleşmezse kod `case _` dalına gelir. `case _` isteğe bağlıdır; her dallanma yapısında joker seçeneği bulunmak zorunda değildir. Eğer bir dallanma yapısında `case _` varsa, yalnızca en sona konabilir; sonrasında başka dallar varsa o dallar erişilemez olur.

Elbette `match-case` sözdiziminin daha birçok ileri kullanımı vardır; bunlardan birleştirme örüntüsünü (OR pattern) şimdiden öğretebiliriz. Örneğin `401`, `403` ve `404` durum kodlarını bir dala, `400` ve `405`'i başka bir dala toplamak istersek kod şöyle yazılabilir.

```python
status_code = int(input('Durum kodu: '))
match status_code:
    case 400 | 405: description = 'Invalid Request'
    case 401 | 403 | 404: description = 'Not Allowed'
    case 418: description = 'I am a teapot'
    case 429: description = 'Too many requests'
    case _: description = 'Unknown Status Code'
print('Durum kodu açıklaması:', description)
```

Çalışma sonucu:

```
Durum kodu: 403
Durum kodu açıklaması: Not Allowed
```

### Dallanma Yapısının Uygulamaları

#### Örnek 1: Parçalı Fonksiyon Değerlendirme

Aşağıdaki gibi bir parçalı fonksiyon var; `x` girilsin, `y` hesaplansın.

$$
y = \begin{cases} 3x - 5, & (x \gt 1) \\\\ x + 2, & (-1 \le x \le 1) \\\\ 5x + 3, & (x \lt -1) \end{cases}
$$

```python
"""
Parçalı fonksiyon değerlendirme

Version: 1.0
Author: 骆昊 (jackfrued)
"""
x = float(input('x = '))
if x > 1:
    y = 3 * x - 5
elif x >= -1:
    y = x + 2
else:
    y = 5 * x + 3
print(f'{y = }')
```

Gerçek geliştirme ihtiyacına göre dallanma yapıları iç içe geçebilir; yani dallanma yapısının `if`, `elif` veya `else` kod bloğunun içinde yeniden dallanma yapısı kurulabilir. Örneğin `if` koşulu sağlanınca oyuncu bölümü geçmiştir; ama bölümü geçtikten sonra, topladığı hazine veya eşya sayısına göre performansına bir değerlendirme de verilir (örneğin bir, iki veya üç yıldız yakma). O zaman `if`'in içinde yeniden bir dallanma yapısı kurmamız gerekir. Aynı şekilde `elif` ve `else` içinde de yeni dallar kurabiliriz; buna iç içe dallanma yapısı denir. Bu düşünceyle yukarıdaki parçalı fonksiyon değerlendirmesi aşağıdaki kodla da yapılabilir.

```python
"""
Parçalı fonksiyon değerlendirme

Version: 1.1
Author: 骆昊 (jackfrued)
"""
x = float(input('x = '))
if x > 1:
    y = 3 * x - 5
else:
    if x >= -1:
        y = x + 2
    else:
        y = 5 * x + 3
print(f'{y = }')
```

> **Not**: Yukarıdaki iki yazımdan hangisinin daha iyi olduğunu kendiniz hissedip değerlendirebilirsiniz. "[**Python Zen'i**](https://zhuanlan.zhihu.com/p/111843067)"nde şöyle bir söz vardır: "**Flat is better than nested**" (Düz yapı, iç içe yapıdan iyidir). "Düz" kodun daha iyi olduğunun düşünülmesinin nedeni, iç içe geçme düzeyi çok artarsa kodun okunabilirliğinin ciddi şekilde bozulmasıdır. Bu yüzden ben şahsen ilk yazımı öneriyorum.

#### Örnek 2: 100'lük Notu Harfe Çevirme

Gereksinim: Girilen not 90 ve üzeriyse `A`; 80 ile 90 arasındaysa (90 hariç) `B`; 70 ile 80 arasındaysa (80 hariç) `C`; 60 ile 70 arasındaysa (70 hariç) `D`; 60'ın altındaysa `E` çıktısı verilsin.

```python
"""
100'lük notu harf notuna çevirme

Version: 1.0
Author: 骆昊 (jackfrued)
"""
score = float(input('Notu girin: '))
if score >= 90:
    grade = 'A'
elif score >= 80:
    grade = 'B'
elif score >= 70:
    grade = 'C'
elif score >= 60:
    grade = 'D'
else:
    grade = 'E'
print(f'{grade = }')
```
#### Örnek 3: Üçgenin Çevresini ve Alanını Hesaplama

Gereksinim: Üç kenarın uzunluğu girilsin; bu kenarlar bir üçgen oluşturabiliyorsa çevre ve alan hesaplansın; oluşturamıyorsa "üçgen oluşturulamaz" mesajı verilsin.

```python
"""
Üçgenin çevresini ve alanını hesaplama

Version: 1.0
Author: 骆昊 (jackfrued)
"""
a = float(input('a = '))
b = float(input('b = '))
c = float(input('c = '))
if a + b > c and a + c > b and b + c > a:
    perimeter = a + b + c
    print(f'Çevre: {perimeter}')
    s = perimeter / 2
    area = (s * (s - a) * (s - b) * (s - c)) ** 0.5
    print(f'Alan: {area}')
else:
    print('Bu kenarlar bir üçgen oluşturamaz')
```
> **Not:** Yukarıdaki `if` koşulu, herhangi iki kenarın toplamının üçüncü kenardan büyük olduğunu ifade eder; bu, bir üçgen oluşturabilmenin gerekli koşuludur. Bu koşul sağlandığında çevre ve alanı hesaplayıp yazdırırız; bu yüzden `if`'in altındaki beş deyim aynı girintiyi korur, bir bütündür ve `if` koşulu sağlanırsa hepsi çalışır. İşte bu, daha önce bahsettiğimiz kod bloğu kavramıdır. Ayrıca yukarıda üçgenin alanını hesaplayan formüle Heron formülü denir. Kenar uzunlukları $\small{a}$, $\small{b}$, $\small{c}$ olan bir üçgenin alanı $\small{A}$ şu formülle bulunur: $\small{A = \sqrt{s(s-a)(s-b)(s-c)}}$, burada $s=\frac{a + b + c}{2}$ yarı çevredir.
