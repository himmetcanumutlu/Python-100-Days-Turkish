## Yaygın Veri Yapıları: Demet (Tuple)

> **Translated to Turkish by** himmetcanumutlu

Önceki iki derste Python'daki listeyi anlattık; liste kap tipinde bir veri tipidir; liste tipindeki değişkenlerle birden çok veri saklayabilir ve döngüyle veriler üzerinde toplu işlem yapabiliriz. Elbette Python'da başka kap tipleri de vardır. Şimdi size bir başka kap tipini anlatalım: adı **demet (tuple)**.

### Demetin Tanımı ve İşlemleri

Python dilinde demet de birden çok elemanın belirli bir sırayla oluşturduğu bir dizidir. Demetin listeden farkı, **demetin değiştirilemez (immutable) bir tip olmasıdır**; yani demet tipindeki bir değişken bir kez tanımlandığında içindeki elemanlar eklenemez veya silinemez ve elemanların değeri de değiştirilemez. Demetteki bir elemanı değiştirmeye çalışırsanız `TypeError` hatası oluşur ve program çöker. Demet tanımlamak için genellikle `(x, y, z)` biçimindeki hazır değer sözdizimi kullanılır; demet tipinin desteklediği operatörler listeyle aynıdır; aşağıdaki koda bakalım.

```python
# Üç elemanlı bir demet tanımla
t1 = (35, 12, 98)
# Dört elemanlı bir demet tanımla
t2 = ('骆昊', 45, True, 'Sichuan Chengdu')

# Değişkenin tipini kontrol et
print(type(t1))  # <class 'tuple'>
print(type(t2))  # <class 'tuple'>

# Demetteki eleman sayısını gör
print(len(t1))  # 3
print(len(t2))  # 4

# İndeksleme işlemi
print(t1[0])    # 35
print(t1[2])    # 98
print(t2[-1])   # Sichuan Chengdu

# Dilimleme işlemi
print(t2[:2])   # ('骆昊', 45)
print(t2[::3])  # ('骆昊', 'Sichuan Chengdu')

# Demetteki elemanlar üzerinde döngüyle gezinme
for elem in t1:
    print(elem)

# Üyelik işlemi
print(12 in t1)         # True
print(99 in t1)         # False
print('Hao' not in t2)  # True

# Birleştirme işlemi
t3 = t1 + t2
print(t3)  # (35, 12, 98, '骆昊', 45, True, 'Sichuan Chengdu')

# Karşılaştırma işlemi
print(t1 == t3)            # False
print(t1 >= t3)            # False
print(t1 <= (35, 11, 99))  # False
```

Bir demette iki eleman varsa buna ikili demet; beş eleman varsa beşli demet deriz. Dikkat etmeniz gereken bir nokta: `()` boş demeti ifade eder; ancak demette yalnızca bir eleman varsa bir virgül eklemek gerekir. Aksi takdirde `()` demeti ifade eden hazır değer sözdizimi değil, işlem önceliğini değiştiren parantez olur. Bu yüzden `('hello', )` ve `(100, )` tek elemanlı demetken, `('hello')` yalnızca string, `(100)` ise yalnızca tam sayıdır. Bunu aşağıdaki kodla doğrulayabiliriz.

```python
a = ()
print(type(a))  # <class 'tuple'>
b = ('hello')
print(type(b))  # <class 'str'>
c = (100)
print(type(c))  # <class 'int'>
d = ('hello', )
print(type(d))  # <class 'tuple'>
e = (100, )
print(type(e))  # <class 'tuple'>
```

### Paketleme ve Çözme İşlemleri

Virgülle ayrılmış birden çok değeri bir değişkene atadığımızda, bu değerler **paketlenerek** bir demet tipine dönüşür; bir demeti birden çok değişkene atadığımızda ise demet **çözülerek** birden çok değere ayrılır ve sırayla karşılık gelen değişkenlere atanır; aşağıdaki kod gibidir.

```python
# Paketleme işlemi
a = 1, 10, 100
print(type(a))  # <class 'tuple'>
print(a)        # (1, 10, 100)
# Çözme işlemi
i, j, k = a
print(i, j, k)  # 1 10 100
```

Çözme sırasında çözülen eleman sayısı ile değişken sayısı uyuşmazsa `ValueError` hatası oluşur; hata mesajı şöyledir: `too many values to unpack` (çözülecek değer çok fazla) veya `not enough values to unpack` (çözülecek değer yetersiz).

```python
a = 1, 10, 100, 1000
# i, j, k = a             # ValueError: too many values to unpack (expected 3)
# i, j, k, l, m, n = a    # ValueError: not enough values to unpack (expected 6, got 4)
```

Değişken sayısının eleman sayısından az olduğu durumlarda bir çözüm yolu **yıldızlı ifade** kullanmaktır. Yıldızlı ifadeyle bir değişkenin birden çok değer almasını sağlayabiliriz; kod aşağıdaki gibidir. İki noktaya dikkat etmek gerekir: öncelikle, yıldızlı ifadeyle süslenen değişken bir listeye dönüşür; listede 0 veya daha fazla eleman bulunur. İkincisi, çözme sözdiziminde yıldızlı ifade yalnızca bir kez kullanılabilir.

```python
a = 1, 10, 100, 1000
i, j, *k = a
print(i, j, k)        # 1 10 [100, 1000]
i, *j, k = a
print(i, j, k)        # 1 [10, 100] 1000
*i, j, k = a
print(i, j, k)        # [1, 10] 100 1000
*i, j = a
print(i, j)           # [1, 10, 100] 1000
i, *j = a
print(i, j)           # 1 [10, 100, 1000]
i, j, k, *l = a
print(i, j, k, l)     # 1 10 100 [1000]
i, j, k, l, *m = a
print(i, j, k, l, m)  # 1 10 100 1000 []
```

Şunu belirtmek gerekir ki çözme sözdizimi tüm diziler için geçerlidir; yani daha önce anlattığımız liste, `range` fonksiyonunun oluşturduğu aralık dizisi ve hatta string bile çözme sözdizimini kullanabilir. Aşağıdaki kodu çalıştırıp nasıl bir sonuç çıkacağını görebilirsiniz.

```python
a, b, *c = range(1, 10)
print(a, b, c)
a, b, c = [1, 10, 100]
print(a, b, c)
a, *b, c = 'hello'
print(a, b, c)
```

### Değişken Değerlerini Takas Etme

Değişkenlerin değerlerini takas etmek kod yazarken sık kullanılan bir işlemdir; ancak birçok programlama dilinde iki değişkenin değerini takas etmek için bir ara değişken gerekir; ara değişken kullanılmazsa anlaşılması güç bitsel işlemlere başvurmak gerekir. Python'da iki değişken `a` ve `b`'nin değerlerini takas etmek için aşağıdaki kodu kullanmanız yeterlidir.

```python
a, b = b, a
```

Aynı şekilde üç değişken `a`, `b`, `c`'nin değerlerini döngüsel olarak değiştirmek — yani `b`'nin değerini `a`'ya, `c`'nin değerini `b`'ye, `a`'nın değerini `c`'ye atamak — istersek yine aynı yöntemi kullanabiliriz.

```python
a, b, c = b, c, a
```

Belirtmek gerekir ki yukarıdaki işlem paketleme ve çözme sözdizimini kullanmaz; Python'un bytecode komutlarında bu işlemi doğrudan gerçekleştiren `ROT_TWO` ve `ROT_THREE` gibi komutlar vardır, verimlilikleri çok yüksektir. Ancak üçten fazla değişkenin değerini sırayla takas etmek gerekiyorsa doğrudan kullanılabilecek bir bytecode komutu yoktur; değişkenler arası değer takası paketleme-çözme yoluyla yapılmalıdır.

### Demet ve Listenin Karşılaştırılması

Burada üzerinde durulmaya değer bir soru var: Python'da liste tipi zaten varken neden demet gibi bir tipe ihtiyaç var? Bu soru yeni başlayanlar için biraz zor görünebilir; sorun değil; önce görüşümüzü ortaya koyalım, siz öğrendikçe yavaş yavaş kavrarsınız.

1. Demet değiştirilemez bir tiptir; **değiştirilemez tipler çok iş parçacıklı (multi-thread) ortamlara daha uygundur**, çünkü eş zamanlı erişimde değişken senkronizasyonunun getirdiği ek yükü azaltır. Bu noktayı eş zamanlı programlamayı anlatırken birlikte tartışacağız.

2. Demet değiştirilemez bir tiptir; genellikle **değiştirilemez tiplerin oluşturulma süresi, karşılık gelen değiştirilebilir tipten daha iyidir**. `timeit` modülünün `timeit` fonksiyonuyla aynı elemanları içeren demet ve listeyi oluşturmanın süresini ölçebiliriz; `timeit` fonksiyonunun `number` parametresi kodun kaç kez çalıştırılacağını belirtir. Aşağıdaki kodda `1`'den `9`'a kadar tam sayıları saklayan liste ve demet oluşturuyoruz; her işlem `10000000` kez çalıştırılıp süre ölçülüyor.

   ```python
   import timeit
   
   print('%.3f saniye' % timeit.timeit('[1, 2, 3, 4, 5, 6, 7, 8, 9]', number=10000000))
   print('%.3f saniye' % timeit.timeit('(1, 2, 3, 4, 5, 6, 7, 8, 9)', number=10000000))
   ```

   Çıktı:

   ```
   0.635 saniye
   0.078 saniye
   ```

   > **Not**: Yukarıdaki kodun çalışma sonucu donanım ve yazılım sistemine göre değişir. Şu an kullandığım bilgisayarda `10000000` kez liste oluşturma işlemi `0.635` saniye, `10000000` kez demet oluşturma işlemi ise `0.078` saniye sürüyor; açıkça demet oluşturmak daha hızlı ve ikisi arasında mertebe farkı var. Bu kodu kendi bilgisayarınızda çalıştırıp sonucunuzu yorum bölümüne yazabilirsiniz; bakalım kimin bilgisayarı daha güçlü.

Elbette Python'daki demet ve liste tipleri birbirine dönüştürülebilir; bu işlemi aşağıdaki kodla yapabiliriz.

```python
infos = ('骆昊', 45, True, 'Sichuan Chengdu')
# Demeti listeye dönüştür
print(list(infos))  # ['骆昊', 45, True, 'Sichuan Chengdu']

frts = ['apple', 'banana', 'orange']
# Listeyi demete dönüştür
print(tuple(frts))  # ('apple', 'banana', 'orange')
```

### Özet

**Liste ve demet, kap tipinde veri tipleridir**; yani bir değişken birden çok veri saklayabilir ve ikisi de elemanları belirli bir sırayla düzenleyen sıralı kaplardır. **Liste değiştirilebilir**, **demet ise değiştirilemez bir veri tipidir**; bu yüzden listeye eleman ekleyebilir, eleman silebilir, elemanları temizleyebilir, sıralayıp ters çevirebilirsiniz; ancak bu işlemler demet için geçerli değildir. Liste ve demet; **birleştirme işlemi**, **üyelik işlemi**, **indeksleme işlemi** ve **dilimleme işlemini** destekler. Birazdan anlatacağımız string tipi de bu işlemleri destekler; çünkü string, karakterlerin belirli bir sırayla oluşturduğu bir dizidir; bu noktada üçü arasında fark yoktur. **Listeyi oluşturmak için liste anlama sözdizimini kullanmanızı öneririz**; hem kullanışlıdır hem de çok verimlidir; Python dilinin çok karakteristik bir sözdizimidir.
