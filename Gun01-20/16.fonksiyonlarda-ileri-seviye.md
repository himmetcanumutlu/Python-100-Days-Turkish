## Fonksiyon Kullanımında İleri Seviye

> **Translated to Turkish by** himmetcanumutlu

Fonksiyon tanımlama ve kullanma bilgilerini keşfetmeye devam ediyoruz. Önceki derslerden, fonksiyonların bağımsız değişkeni (parametre) ve bağımlı değişkeni (dönüş değeri) olduğunu biliyoruz; bağımsız değişken de bağımlı değişken de herhangi bir veri tipinde olabilir. O zaman küçük bir soru var: fonksiyonu, fonksiyonun parametresi olarak; fonksiyonu da fonksiyonun dönüş değeri olarak kullanabilir miyiz? Önce sonucu söyleyelim: **Python'daki fonksiyonlar "birinci sınıf fonksiyondur"**. "Birinci sınıf fonksiyon", fonksiyonun bir değişkene atanabildiği, fonksiyonun parametresi olabildiği ve fonksiyonun dönüş değeri olabildiği anlamına gelir. Bir fonksiyonu, başka fonksiyonların parametresi ya da dönüş değeri olarak kullanma biçimine genellikle "yüksek dereceli fonksiyon" deriz.

### Yüksek Dereceli Fonksiyonlar

Daha önce anlattığımız bir örneğe dönelim: istediğimiz kadar parametre alan ve içindeki `int` ya da `float` tipindeki elemanları toplayan bir fonksiyon tasarlayın. Önceki kodu biraz ayarlayıp daha derli toplu hale getirelim; aşağıdaki gibidir.

```python
def calc(*args, **kwargs):
    items = list(args) + list(kwargs.values())
    result = 0
    for item in items:
        if type(item) in (int, float):
            result += item
    return result
```

Yukarıdaki `calc` fonksiyonunun yalnızca birden çok parametreyi toplamakla kalmayıp daha fazla, hatta özelleştirilmiş ikili işlemler de yapabilmesini istersek ne yapmalıyız? Yukarıdaki kod yalnızca toplama yapabilir; çünkü fonksiyonda `+=` operatörü kullanılıyor ve bu, fonksiyon ile toplama işlemi arasında bir bağ (coupling) oluşturuyor. Bu bağı çözebilirsek fonksiyonun genelliği ve esnekliği artar. Bağı çözmenin yolu, `+` operatörünü bir fonksiyon çağrısına dönüştürüp onu fonksiyonun parametresi olarak tasarlamaktır; kod aşağıdaki gibidir.

```python
def calc(init_value, op_func, *args, **kwargs):
    items = list(args) + list(kwargs.values())
    result = init_value
    for item in items:
        if type(item) in (int, float):
            result = op_func(result, item)
    return result
```

Dikkat: Yukarıdaki fonksiyona iki parametre eklendi; `init_value` işlemin başlangıç değerini, `op_func` ise ikili işlem fonksiyonunu temsil eder. Değiştirilmiş fonksiyonu çağırmak için önce toplama ve çarpma yapan fonksiyonları tanımlayalım; kod aşağıdaki gibidir.

```python
def add(x, y):
    return x + y


def mul(x, y):
    return x * y
```

Toplama işlemi yapmak istiyorsak `calc` fonksiyonunu aşağıdaki gibi çağırabiliriz.

```python
print(calc(0, add, 1, 2, 3, 4, 5))  # 15
```

Çarpma işlemi yapmak istiyorsak `calc` fonksiyonunu aşağıdaki gibi çağırabiliriz.

```python
print(calc(1, mul, 1, 2, 3, 4, 5))  # 120 
```

Yukarıdaki `calc` fonksiyonu, operatörü fonksiyonun parametresine dönüştürerek toplama işlemiyle olan bağı çözdü; bu, çok akıllıca ve pratik bir programlama tekniğidir; ancak yeni başlayanlar için anlaşılması zor olabilir; üzerinde düşünmenizi öneririz. Dikkat edilmesi gereken nokta: yukarıdaki kodda fonksiyonu başka fonksiyona parametre olarak geçmek ile fonksiyonu doğrudan çağırmak arasında belirgin bir fark vardır. Fonksiyon çağırmak için fonksiyon adından sonra parantez koymak gerekir; fonksiyonu parametre olarak geçerken ise yalnızca fonksiyon adı yeterlidir**.

Önceden `add` ve `mul` fonksiyonlarını tanımlamadıysak, Python standart kütüphanesinin `operator` modülünün sunduğu `add` ve `mul` fonksiyonlarını da kullanabiliriz; bunlar sırasıyla toplama ve çarpma ikili işlemlerini temsil eder; doğrudan alıp kullanabiliriz; kod aşağıdaki gibidir.

```python
import operator

print(calc(0, operator.add, 1, 2, 3, 4, 5))  # 15
print(calc(1, operator.mul, 1, 2, 3, 4, 5))  # 120
```

Python yerleşik fonksiyonları arasında pek çok yüksek dereceli fonksiyon vardır; daha önce sözünü ettiğimiz `filter` ve `map` fonksiyonları yüksek dereceli fonksiyonlardır. Birincisi dizideki elemanları filtrelemeyi, ikincisi dizideki elemanları eşlemeyi (dönüştürmeyi) gerçekleştirir. Örneğin bir tam sayı listesinden tek sayıları çıkarıp tüm çift sayıların karesini alarak yeni bir liste elde etmek istiyorsak, bu iki fonksiyonu doğrudan kullanabiliriz; somut yöntem aşağıdaki gibidir.

```python
def is_even(num):
    """num'ın çift olup olmadığını belirle"""
    return num % 2 == 0


def square(num):
    """Karesini al"""
    return num ** 2


old_nums = [35, 12, 8, 99, 60, 52]
new_nums = list(map(square, filter(is_even, old_nums)))
print(new_nums)  # [144, 64, 3600, 2704]
```

Elbette yukarıdaki kodun işlevini gerçekleştirmek için liste anlama da kullanılabilir; liste anlama yöntemi daha sade ve zariftir.

```python
old_nums = [35, 12, 8, 99, 60, 52]
new_nums = [num ** 2 for num in old_nums if num % 2 == 0]
print(new_nums)  # [144, 64, 3600, 2704]
```

Şimdi `sorted` adlı yerleşik fonksiyonu tartışalım; kap tipindeki veri türlerinin (liste, sözlük vb.) elemanlarını sıralamayı gerçekleştirir. Daha önce `list` tipinin `sort` metodunu anlatmıştık; o, liste elemanlarını sıralar. `sorted` fonksiyonu işlev açısından listenin `sort` metodundan farksızdır; ancak asıl listeyi doğrudan değiştirmek yerine sıralanmış liste nesnesini döndürür. Buna **fonksiyonun yan etkisiz tasarımı** deriz; yani fonksiyon çağrısı, dönüş değeri üretmenin dışında programın durumuna veya dış ortama başka hiçbir etki yapmaz. `sorted` fonksiyonuyla sıralarken, yüksek dereceli fonksiyon biçiminde sıralama kuralı özelleştirilebilir; aşağıdaki örnekle açıklayalım.

```python
old_strings = ['in', 'apple', 'zoo', 'waxberry', 'pear']
new_strings = sorted(old_strings)
print(new_strings)  # ['apple', 'in', 'pear', 'waxberry', 'zoo']
```

Yukarıdaki kod size yabancı değil; ancak liste elemanlarını alfabetik sıraya göre değil de string uzunluğuna göre sıralamak istersek, `sorted` fonksiyonuna `key` adında bir parametre geçip, `key` parametresine string uzunluğunu alan `len` fonksiyonunu atayabiliriz; bu fonksiyonu daha önceki derslerde anlatmıştık; kod aşağıdaki gibidir.

```python
old_strings = ['in', 'apple', 'zoo', 'waxberry', 'pear']
new_strings = sorted(old_strings, key=len)
print(new_strings)  # ['in', 'zoo', 'pear', 'apple', 'waxberry']
```

> **Not**: Liste tipinin `sort` metodunun da aynı `key` parametresi vardır; merak edenler kendileri deneyebilir.

### Lambda Fonksiyonları

Yüksek dereceli fonksiyonları kullanırken, parametre ya da dönüş değeri olan fonksiyon çok basitse, tek satır kodla tamamlanabiliyorsa ve fonksiyonun yeniden kullanımını düşünmemize gerek yoksa lambda fonksiyonunu kullanabiliriz. Python'daki lambda fonksiyonu adı olmayan bir fonksiyondur; bu yüzden birçok kişi ona **anonim fonksiyon** der. Lambda fonksiyonu yalnızca bir satır kod içerebilir; koddaki ifadenin ürettiği işlem sonucu, bu anonim fonksiyonun dönüş değeridir. Önceki kodda yazdığımız `is_even` ve `square` fonksiyonları yalnızca birer satırdır; bunları lambda fonksiyonuyla değiştirmeyi düşünebiliriz; kod aşağıdaki gibidir.

```python
old_nums = [35, 12, 8, 99, 60, 52]
new_nums = list(map(lambda x: x ** 2, filter(lambda x: x % 2 == 0, old_nums)))
print(new_nums)  # [144, 64, 3600, 2704]
```

Yukarıdaki koddan da görülebileceği gibi, lambda fonksiyonu tanımlamanın anahtar sözcüğü `lambda`'dır; ardına fonksiyonun parametreleri gelir; birden çok parametre varsa virgülle ayrılır. İki noktadan sonraki kısım fonksiyonun gövdesidir; genellikle bir ifadedir; ifadenin işlem sonucu lambda fonksiyonunun dönüş değeridir; `return` anahtar sözcüğü yazmaya gerek yoktur.

Daha önce Python'daki fonksiyonların "birinci sınıf fonksiyon" olduğunu, fonksiyonların doğrudan değişkene atanabildiğini söylemiştik. Lambda fonksiyonunu öğrendikten sonra, daha önce yazdığımız bazı fonksiyonları tek satır kodla gerçekleştirebiliriz; aşağıdaki faktöriyel hesaplama ve asal sayı belirleme fonksiyonlarını anlayıp anlayamadığınıza bakın.

```python
import functools
import operator

# Tek satır kodla faktöriyel hesaplayan fonksiyon
fac = lambda n: functools.reduce(operator.mul, range(2, n + 1), 1)

# Tek satır kodla asal sayı belirleyen fonksiyon
is_prime = lambda x: all(map(lambda f: x % f, range(2, int(x ** 0.5) + 1)))

# Lambda fonksiyonunu çağır
print(fac(6))        # 720
print(is_prime(37))  # True
```

> **İpucu 1**: Yukarıda kullanılan `reduce` fonksiyonu, Python standart kütüphanesi `functools` modülündeki bir fonksiyondur; bir grup veri üzerinde indirgeme işlemi yapar; daha önce tanımladığımız `calc` fonksiyonuna benzer. İlk parametresi işlemi temsil eden fonksiyon, ikinci parametresi işlenecek veri, üçüncü parametresi ise işlemin başlangıç değeridir. Açıkça `reduce` fonksiyonu da yüksek dereceli bir fonksiyondur; `filter` ve `map` fonksiyonlarıyla birlikte veri işlemede çok kritik üç eylemi oluşturur: **filtreleme**, **eşleme** ve **indirgeme**.
>
> **İpucu 2**: Yukarıdaki asal sayı belirleyen lambda fonksiyonu, `range` fonksiyonuyla 2'den $\small{\sqrt{x}}$'e kadar bir aralık oluşturup bu aralıkta `x`'in böleni olup olmadığını kontrol eder. `all` fonksiyonu da Python yerleşik fonksiyonudur; geçilen dizideki tüm mantıksal değerler `True` ise `all` fonksiyonu `True`, aksi halde `False` döndürür.

### Kısmi (Partial) Fonksiyonlar

Kısmi fonksiyon, bir fonksiyonun belirli parametrelerini sabitleyip yeni bir fonksiyon üretmektir; böylece fonksiyonu her çağırışta aynı parametreyi geçmeye gerek kalmaz. Python dilinde kısmi fonksiyon oluşturmak için `functools` modülünün `partial` fonksiyonunu kullanabiliriz. Örneğin `int` fonksiyonu varsayılan olarak string'i onluk tabanda tam sayıya çevirir; onun `base` parametresini değiştirerek, sırasıyla ikilik, sekizlik ve onaltılık string'leri tam sayıya çeviren üç yeni fonksiyon tanımlayabiliriz; kod aşağıdaki gibidir.

```python
import functools

int2 = functools.partial(int, base=2)
int8 = functools.partial(int, base=8)
int16 = functools.partial(int, base=16)

print(int('1001'))    # 1001

print(int2('1001'))   # 9
print(int8('1001'))   # 513
print(int16('1001'))  # 4097
```

Fark ettiniz mi bilmem, `partial` fonksiyonunun ilk parametresi de dönüş değeri de fonksiyondur; geçilen fonksiyonu işleyip yeni bir fonksiyon olarak döndürür. Kısmi fonksiyon kurarak, gerçek kullanım senaryosuna göre asıl fonksiyonu kullanımı daha pratik yeni bir fonksiyona dönüştürebiliriz; bu operasyon size ilginç gelmedi mi?

###  Özet

Python'daki fonksiyonlar birinci sınıf fonksiyondur; değişkene atanabilir, fonksiyonun parametresi ve dönüş değeri olabilir; bu da Python'da yüksek dereceli fonksiyon kullanabileceğimiz anlamına gelir. Yüksek dereceli fonksiyon kavramı yeni başlayanlara pek dostane değildir, ama fonksiyon tasarımında esneklik getirir. Tanımlayacağımız fonksiyon çok basitse, yalnızca bir satır koddan oluşuyorsa ve onu yeniden kullanmak için fonksiyon adına ihtiyaç duymuyorsak lambda fonksiyonunu kullanabiliriz.
