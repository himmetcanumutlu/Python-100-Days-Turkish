## Nesne Yönelimli Programlamada İleri Seviye

> **Translated to Turkish by** himmetcanumutlu

Önceki bölümde Python nesne yönelimli programlamanın bazı temel bilgilerini anlattık; bu bölümde nesne yönelimli programlamayla ilgili içeriği tartışmaya devam ediyoruz.

### Görünürlük ve Özellik Dekoratörleri

Birçok nesne yönelimli programlama dilinde, nesnenin öznitelikleri genellikle özel (private) veya korumalı (protected) üye olarak ayarlanır; basitçe söylemek gerekirse bu özniteliklere doğrudan erişime izin verilmez. Nesnenin metotları ise genellikle geneldir (public); çünkü genel metotlar nesnenin alabileceği mesajlardır ve nesnenin dışarıya sunduğu çağrı arayüzüdür; işte buna **erişim görünürlüğü** denir. Python'da, nesne özniteliğinin adına ön ek olarak alt çizgi ekleyerek özniteliğin erişim görünürlüğünü belirtebiliriz. Örneğin `__name` bir özel özniteliği, `_name` ise bir korumalı özniteliği ifade eder; kod aşağıdaki gibidir.

```python
class Student:

    def __init__(self, name, age):
        self.__name = name
        self.__age = age

    def study(self, course_name):
        print(f'{self.__name}, {course_name} dersini çalışıyor.')


stu = Student('Ahmet Yılmaz', 20)
stu.study('Python Programlama')
print(stu.__name)  # AttributeError: 'Student' object has no attribute '__name'
```

Yukarıdaki kodun son satırı `AttributeError` (öznitelik hatası) üretir; hata mesajı şudur: `'Student' object has no attribute '__name'`. Görüldüğü gibi `__` ile başlayan `__name` özniteliği adeta özeldir; sınıfın dışında doğrudan erişilemez; ancak sınıfın içindeki `study` metodunda `self.__name` ile bu özniteliğe erişilebilir. Belirtmek gerekir ki Python dilini kullanan çoğu kişi, sınıf tanımlarken genellikle nesnenin özniteliklerini özel veya korumalı yapmayı tercih etmez; ünlü bir sözde dendiği gibi: "**We are all consenting adults here**" (Burada hepimiz rıza gösteren yetişkinleriz). Yetişkinler kendi davranışlarından sorumlu olabilir; erişim görünürlüğünü Python dilinin kendisiyle sınırlamaya gerek yoktur. Aslında çoğu programcı **açıklığın kapalılıktan daha iyi olduğunu** düşünür; nesnenin özniteliklerini özelleştirmek vazgeçilmez bir şey değildir. Bu yüzden Python dili anlamsal olarak en katı sınırlamayı getirmez; yani yukarıdaki kodda isterseniz `stu._Student__name` biçimiyle `__name` özel özniteliğine yine de erişebilirsiniz; merak edenler kendileri deneyebilir.

### Dinamik Öznitelikler

Python dili dinamik bir dildir. Vikipedi'nin dinamik dil açıklaması şöyledir: "Çalışma zamanında yapısı değiştirilebilen dil; örneğin yeni fonksiyonlar, nesneler ve hatta kod eklenebilir, mevcut fonksiyonlar silinebilir ya da başka yapısal değişiklikler yapılabilir." Dinamik diller çok esnektir; günümüzde popüler olan Python ve JavaScript dinamik dillerdir; bunların yanı sıra PHP, Ruby gibi diller de dinamik dildir; C, C++ gibi diller ise dinamik dil değildir.

Python'da nesneye dinamik olarak öznitelik ekleyebiliriz; bu, Python'ın dinamik tipli bir dil olmasının ayrıcalığıdır; kod aşağıdaki gibidir. Hatırlatmak isteriz ki nesnenin metotları aslında özünde nesnenin öznitelikleridir; nesneye alınamayan bir mesaj gönderilirse, oluşan hata yine `AttributeError` olur.

```python
class Student:

    def __init__(self, name, age):
        self.name = name
        self.age = age


stu = Student('Ahmet Yılmaz', 20)
stu.sex = 'Erkek'  # Öğrenci nesnesine dinamik olarak sex özniteliği ekle
```

Nesneyi kullanırken nesneye dinamik olarak öznitelik eklenmesini istemiyorsak, Python dilindeki `__slots__` sihrini kullanabiliriz. `Student` sınıfı için sınıf içinde `__slots__ = ('name', 'age')` belirtirsek, `Student` sınıfının nesneleri yalnızca `name` ve `age` özniteliklerine sahip olabilir; başka öznitelik dinamik eklenmeye çalışılırsa hata oluşur; kod aşağıdaki gibidir.

```python
class Student:
    __slots__ = ('name', 'age')

    def __init__(self, name, age):
        self.name = name
        self.age = age


stu = Student('Ahmet Yılmaz', 20)
# AttributeError: 'Student' object has no attribute 'sex'
stu.sex = 'Erkek'
```

### Statik Metotlar ve Sınıf Metotları

Daha önce sınıfta tanımladığımız metotların hepsi nesne metoduydu; başka bir deyişle bu metotlar nesnenin alabileceği mesajlardı. Nesne metotlarının dışında sınıfta statik metotlar ve sınıf metotları da olabilir; bu iki metot türü sınıfa gönderilen mesajlardır ve ikisi arasında esaslı bir fark yoktur. Nesne yönelimli dünyada her şey nesnedir; tanımladığımız her sınıf da aslında bir nesnedir; statik metotlar ve sınıf metotları ise sınıf nesnesine gönderilen mesajlardır. Peki hangi mesajlar doğrudan sınıf nesnesine gönderilir?

Bir örnek verelim: üçgen sınıfı tanımlayalım; üç kenarın uzunluğunu geçerek üçgen oluşturalım, çevre ve alan hesaplayan metotlar sunalım. Çevre ve alan hesaplama kuşkusuz üçgen nesnesinin metotlarıdır; bunda şüphe yok. Ancak üçgen nesnesi oluşturulurken geçilen üç kenar mutlaka üçgen oluşturmayabilir; bunun için verilen üç kenarın üçgen oluşturup oluşturmadığını doğrulayan bir metot yazmamız gerekir. Bu metot açıkça bir nesne metodu değildir; çünkü bu metot çağrıldığında üçgen nesnesi henüz oluşturulmamıştır. Bu tür metotları statik metot veya sınıf metodu olarak tasarlayabiliriz; yani bu tür metotlar üçgen nesnesine gönderilen mesaj değil, üçgen sınıfına gönderilen mesajdır; kod aşağıdaki gibidir.

```python
class Triangle(object):
    """Üçgen"""

    def __init__(self, a, b, c):
        """Başlatıcı metot"""
        self.a = a
        self.b = b
        self.c = c

    @staticmethod
    def is_valid(a, b, c):
        """Üç kenarın üçgen oluşturup oluşturmadığını belirle (statik metot)"""
        return a + b > c and b + c > a and a + c > b

    # @classmethod
    # def is_valid(cls, a, b, c):
    #     """Üç kenarın üçgen oluşturup oluşturmadığını belirle (sınıf metodu)"""
    #     return a + b > c and b + c > a and a + c > b

    def perimeter(self):
        """Çevreyi hesapla"""
        return self.a + self.b + self.c

    def area(self):
        """Alanı hesapla"""
        p = self.perimeter() / 2
        return (p * (p - self.a) * (p - self.b) * (p - self.c)) ** 0.5
      

if Triangle.is_valid(3, 4, 5):
    t = Triangle(3, 4, 5)
    print(f'Çevre: {t.perimeter()}')
    print(f'Alan: {t.area()}')
else:
    print('Geçersiz kenar uzunlukları!!!')
```

Yukarıdaki kod, `is_valid` metodunun `Triangle` sınıfının statik metodu olduğunu `staticmethod` dekoratörüyle belirtir; sınıf metodu belirtmek istiyorsanız `classmethod` dekoratörünü kullanabilirsiniz (yukarıdaki kodun 15~18. satırlarındaki gibi). Statik metot ve sınıf metodu doğrudan `sınıf adı.metot adı` biçimiyle çağrılabilir; ikisinin farkı, sınıf metodunun ilk parametresinin sınıf nesnesinin kendisi olması, statik metodun ise böyle bir parametresinin olmamasıdır. Kısaca özetlersek, **nesne metodu, sınıf metodu ve statik metot da "sınıf adı.metot adı" biçimiyle çağrılabilir; fark, metodun ilk parametresinin sıradan bir nesne mi, sınıf nesnesi mi olduğu ya da mesaj alan hiçbir nesnenin olmamasıdır**. Statik metot genellikle doğrudan bağımsız bir fonksiyon olarak da yazılabilir; çünkü belirli bir nesneye bağlı değildir.

Burada ek bir açıklama yapalım: yukarıdaki üçgen çevre ve alan hesaplama metotlarına bir `property` dekoratörü (Python yerleşik tipi) ekleyebiliriz; böylece üçgen sınıfının `perimeter` ve `area` değerleri birer özniteliğe dönüşür; artık metot çağırarak değil, nesnenin özniteliğine erişir gibi doğrudan elde edilir; değiştirilmiş kod aşağıdaki gibidir.

```python
class Triangle(object):
    """Üçgen"""

    def __init__(self, a, b, c):
        """Başlatıcı metot"""
        self.a = a
        self.b = b
        self.c = c

    @staticmethod
    def is_valid(a, b, c):
        """Üç kenarın üçgen oluşturup oluşturmadığını belirle (statik metot)"""
        return a + b > c and b + c > a and a + c > b

    @property
    def perimeter(self):
        """Çevreyi hesapla"""
        return self.a + self.b + self.c

    @property
    def area(self):
        """Alanı hesapla"""
        p = self.perimeter / 2
        return (p * (p - self.a) * (p - self.b) * (p - self.c)) ** 0.5


if Triangle.is_valid(3, 4, 5):
    t = Triangle(3, 4, 5)
    print(f'Çevre: {t.perimeter}')
    print(f'Alan: {t.area}')
else:
    print('Geçersiz kenar uzunlukları!!!')
```

### Kalıtım ve Çok Biçimlilik

Nesne yönelimli programlama dilleri, mevcut bir sınıf temelinde yeni sınıf oluşturmayı destekler; böylece yinelenen kod yazımı azalır. Kalıtım bilgisini sağlayan sınıfa **üst sınıf** (süper sınıf, taban sınıf), kalıtım bilgisini alan sınıfa ise **alt sınıf** (türetilmiş sınıf, türev sınıf) denir. Örneğin bir öğrenci sınıfı ve bir öğretmen sınıfı tanımlayalım; aralarında çok sayıda yinelenen kod olduğunu görürüz; bu yinelenen kodlar, öğretmen ve öğrencinin insan olarak ortak öznitelik ve davranışlarıdır. Bu durumda önce insan sınıfını tanımlayıp, sonra kalıtım yoluyla insan sınıfından öğretmen ve öğrenci sınıflarını türetmeliyiz; kod aşağıdaki gibidir.

```python
class Person:
    """İnsan"""

    def __init__(self, name, age):
        self.name = name
        self.age = age
    
    def eat(self):
        print(f'{self.name} yemek yiyor.')
    
    def sleep(self):
        print(f'{self.name} uyuyor.')


class Student(Person):
    """Öğrenci"""
    
    def __init__(self, name, age):
        super().__init__(name, age)
    
    def study(self, course_name):
        print(f'{self.name}, {course_name} dersini çalışıyor.')


class Teacher(Person):
    """Öğretmen"""

    def __init__(self, name, age, title):
        super().__init__(name, age)
        self.title = title
    
    def teach(self, course_name):
        print(f'{self.name}{self.title}, {course_name} dersini anlatıyor.')



stu1 = Student('Ali Yıldız', 21)
stu2 = Student('Ayşe Demir', 22)
tea1 = Teacher('Veli Kaya', 35, 'Doç. Dr.')
stu1.eat()
stu2.sleep()
tea1.eat()
stu1.study('Python Programlama')
tea1.teach('Python Programlama')
stu2.study('Veri Bilimine Giriş')
```

Kalıtımın sözdizimi, sınıf tanımlarken sınıf adından sonraki parantez içinde mevcut sınıfın üst sınıfını belirtmektir. Bir sınıf tanımlarken üst sınıfının kim olduğu belirtilmezse, varsayılan üst sınıf `object` sınıfıdır. `object` sınıfı, Python'daki en üst sınıftır; yani tüm sınıflar onun alt sınıfıdır; ya doğrudan ya da dolaylı olarak ondan kalıtım alır. Python dili çoklu kalıtımı destekler; yani bir sınıfın bir veya daha fazla üst sınıfı olabilir; çoklu kalıtım konusunu ileride daha ayrıntılı tartışacağız. Alt sınıfın başlatıcı metodunda, üst sınıfın başlatıcı metodunu çağırmak için `super().__init__()` kullanabiliriz; `super` fonksiyonu, Python yerleşik fonksiyonları içinde özellikle mevcut nesnenin üst sınıf nesnesini elde etmek için tasarlanmıştır. Yukarıdaki koddan da görülebileceği gibi, alt sınıf kalıtımla üst sınıfın sunduğu öznitelik ve metotları elde etmenin yanı sıra, kendine özgü öznitelik ve metotlar da tanımlayabilir; bu yüzden alt sınıf, üst sınıftan daha fazla yeteneğe sahiptir. Gerçek geliştirmede sık sık üst sınıf nesnesini alt sınıf nesnesiyle değiştiririz; bu, nesne yönelimli programlamada yaygın bir davranıştır ve "Liskov Yerine Geçme İlkesi" (Liskov Substitution Principle) olarak adlandırılır.

Alt sınıf, üst sınıfın metodunu kalıtım aldıktan sonra metodu **yeniden yazabilir** (geçersiz kılabilir; metodu yeniden gerçekleyebilir). Farklı alt sınıflar, üst sınıfın aynı metoduna farklı gerçekleme sürümleri verebilir; bu tür metotlar program çalışırken **çok biçimli davranış** sergiler (aynı metodu çağırıp farklı işler yapmak). Çok biçimlilik, nesne yönelimli programlamanın en öz kısmıdır; elbette yeni başlayanlar için anlaşılması ve esnek kullanılması en zor kısımdır; bu bilgiyi bir sonraki bölümde özel örneklerle anlatacağız.

### Özet

Python dinamik tipli bir dildir; Python'daki nesnelere dinamik olarak öznitelik eklenebilir; nesnenin metotları da aslında özniteliktir; yalnızca o özniteliğe karşılık gelen şey çağrılabilir bir fonksiyondur. Nesne yönelimli dünyada **her şey nesnedir**; tanımladığımız sınıflar da nesnedir; bu yüzden **sınıflar da mesaj alabilir**; buna karşılık gelen metotlar sınıf metodu veya statik metottur. Kalıtım sayesinde **mevcut sınıftan yeni sınıf oluşturabilir**, mevcut sınıfın kodunun yeniden kullanımını sağlayabiliriz.
