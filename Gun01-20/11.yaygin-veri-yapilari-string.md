### String Tanımı

**String**, **sıfır veya daha fazla karakterden oluşan sonlu bir dizidir**; genellikle şöyle gösterilir:

$$
s = a_1a_2 \cdots a_n \,\,\,\,\, (0 \le n \le \infty)
$$

Python programında tek veya birden çok karakteri tek tırnak ya da çift tırnakla sararak bir string ifade edebiliriz. String içindeki karakterler; özel simgeler, İngilizce harfler, Çince karakterler, Japonca hiragana/katakana, Yunan harfleri, Emoji karakterleri (ör. 💩, 🐷, 🀄️) vb. olabilir.

```python
s1 = 'hello, world!'
s2 = "Merhaba, dünya!❤️"
s3 = '''hello,
wonderful
world!'''
print(s1)
print(s2)
print(s3)
```

#### Kaçış Karakterleri

String içinde `\` (ters eğik çizgi) kullanarak kaçışı (escape) ifade edebiliriz; yani `\`'dan sonraki karakter artık kendi asıl anlamını taşımaz. Örneğin `\n` karakterlerini temsil etmez, satır sonu (yeni satır) demektir; `\t` da `\` ve `t` karakterlerini değil, sekme (tab) karakterini ifade eder. Bu yüzden string'in kendisi `'`, `"`, `\` gibi özel karakterleri içeriyorsa mutlaka `\` ile kaçış işlemi yapılmalıdır. Örneğin tek tırnak veya ters eğik çizgi içeren bir string yazdırmak için aşağıdaki yöntem kullanılır.

```python
s1 = '\'hello, world!\''
s2 = '\\hello, world!\\'
print(s1)
print(s2)
```

#### Ham (Raw) String

Python'da `r` veya `R` ile başlayan bir string türü vardır; bu string'e **ham (raw) string** denir; içindeki her karakter kendi asıl anlamını taşır, kaçış karakteri yoktur. Örneğin `'hello\n'` string'inde `\n` satır sonunu ifade eder; `r'hello\n'` içinde ise `\n` artık satır sonu değil, `\` ve `n` karakterleridir. Aşağıdaki kodu çalıştırıp ne çıktı verdiğine bakabilirsiniz.

```python
s1 = '\it \is \time \to \read \now'
s2 = r'\it \is \time \to \read \now'
print(s1)
print(s2)
```

> **Not**: Yukarıdaki `s1` değişkeninde `\t`, `\r` ve `\n` kaçış karakterleridir. `\t` sekme (tab), `\n` satır sonu (new line), `\r` satır başıdır (carriage return) ve çıktıyı satır başına döndürür. İki `print` fonksiyonunun çıktısını karşılaştırıp farkın ne olduğunu görün!

#### Karakterlerin Özel Gösterimi

Python'da `\`'dan sonra sekizlik veya onaltılık bir sayı gelerek bir karakter temsil edilebilir; örneğin `\141` ve `\x61` küçük `a` harfini temsil eder; birincisi sekizlik, ikincisi onaltılık gösterimdir. Karakterleri temsil etmenin bir başka yolu da `\u`'dan sonra Unicode karakter kodunu yazmaktır; örneğin `骆昊`, Çince "骆昊" ifadesini temsil eder. Aşağıdaki kodu çalıştırıp ne çıktı verdiğine bakın.

```python
s1 = '\141\142\143\x61\x62\x63'
s2 = '骆昊'
print(s1)
print(s2)
```

### String İşlemleri

Python dili, string tipi için çok zengin operatörler sunar; birçok operatör, liste tipinin operatörleriyle benzer işlev görür. Örneğin string'leri birleştirmek için `+` operatörünü, bir string'in içeriğini tekrarlamak için `*` operatörünü, bir string'in başka bir string içerip içermediğini belirlemek için `in` ve `not in` operatörlerini kullanabilir; ayrıca string'den bir veya birkaç karakteri çıkarmak için `[]` ve `[:]` operatörlerini kullanabiliriz.

#### Birleştirme ve Tekrarlama

Aşağıdaki örnek, `+` ve `*` operatörleriyle string birleştirme ve tekrarlama işlemlerini gösterir.

```python
s1 = 'hello' + ', ' + 'world'
print(s1)    # hello, world
s2 = '!' * 3
print(s2)    # !!!
s1 += s2
print(s1)    # hello, world!!!
s1 *= 2
print(s1)    # hello, world!!!hello, world!!!
```

String tekrarı için `*` kullanmak oldukça ilginç bir operatördür; birçok programlama dilinde 10 tane `a` içeren bir string'i ancak `'aaaaaaaaaa'` olarak yazabilirsiniz, oysa Python'da `'a' * 10` yazabilirsiniz. `'aaaaaaaaaa'` yazımının da pek zahmetli olmadığını düşünebilirsiniz; ama düşünün, `a` karakterini 100 veya 1000 kez tekrarlamak gerekseydi ne olurdu?

#### Karşılaştırma İşlemi

İki string tipindeki değişkenin eşitliğini veya büyüklüğünü doğrudan karşılaştırma operatörleriyle belirleyebiliriz. Belirtmek gerekir ki string'ler bilgisayar belleğinde ikili biçimde var olduğundan, string büyüklük karşılaştırması her karakterin karşılık geldiği kodun büyüklüğünü karşılaştırır. Örneğin `A`'nın kodu `65`, `a`'nın kodu `97`'dir; bu yüzden `'A' < 'a'` sonucu aslında `65 < 97` sonucudur ve açıkça `True`'dur. `'boy' < 'bad'` örneğinde ilk karakterler `'b'` olduğundan büyüklük belirlenemez; bu yüzden aslında ikinci karakterler karşılaştırılır; `'o' < 'a'` sonucu `False` olduğundan `'boy' < 'bad'` sonucu `False` olur. İki karakterin kodunun kaç olduğunu bilmiyorsanız, daha önce bahsettiğimiz `ord` fonksiyonunu kullanabilirsiniz. Örneğin `ord('A')` değeri `65`, `ord('昊')` değeri `26122`'dir. Aşağıdaki kod string karşılaştırma işlemlerini gösterir; dikkatle inceleyin.

```python
s1 = 'a whole new world'
s2 = 'hello world'
print(s1 == s2)             # False
print(s1 < s2)              # True
print(s1 == 'hello world')  # False
print(s2 == 'hello world')  # True
print(s2 != 'Hello world')  # True
s3 = '骆昊'
print(ord('骆'))            # 39558
print(ord('昊'))            # 26122
s4 = '王大锤'
print(ord('王'))            # 29579
print(ord('大'))            # 22823
print(ord('锤'))            # 38180
print(s3 >= s4)             # True
print(s3 != s4)             # True
```

#### Üyelik İşlemi

Python'da bir string'in başka bir karakteri veya string'i içerip içermediğini `in` ve `not in` ile belirleyebiliriz; liste tipinde olduğu gibi `in` ve `not in`'e üyelik operatörleri denir ve `True` ya da `False` mantıksal değeri üretir; kod aşağıdaki gibidir.

```python
s1 = 'hello, world'
s2 = 'goodbye, world'
print('wo' in s1)      # True
print('wo' not in s2)  # False
print(s2 in s1)        # False
```

#### String Uzunluğunu Alma

String uzunluğunu almak, liste eleman sayısını almakla aynıdır; yerleşik `len` fonksiyonu kullanılır; kod aşağıdaki gibidir.

```python
s = 'hello, world'
print(len(s))                 # 12
print(len('goodbye, world'))  # 14
```

#### İndeksleme ve Dilimleme

String'in indeksleme ve dilimleme işlemi, liste ve demetten neredeyse farksızdır; çünkü string de sıralı bir dizidir ve elemanlarına ileri ya da geri tam sayı indeksle erişilebilir. Ancak bir noktaya dikkat etmek gerekir: **string değiştirilemez bir tip olduğundan**, **indeksleme işlemiyle string'deki karakterler değiştirilemez**.

```python
s = 'abc123456'
n = len(s)
print(s[0], s[-n])    # a a
print(s[n-1], s[-1])  # 6 6
print(s[2], s[-7])    # c c
print(s[5], s[-4])    # 3 3
print(s[2:5])         # c12
print(s[-7:-4])       # c12
print(s[2:])          # c123456
print(s[:2])          # ab
print(s[::2])         # ac246
print(s[::-1])        # 654321cba
```

Tekrar hatırlatmakta fayda var: indeksleme yaparken indeks sınırı aşarsa `IndexError` hatası oluşur; hata mesajı şudur: `string index out of range` (string indeksi aralığın dışında).

### Karakterler Üzerinde Gezinme

String'deki her karakter üzerinde gezinmek istiyorsanız `for-in` döngüsünü kullanabilirsiniz; iki yolu vardır.

Yöntem 1:

```python
s = 'hello'
for i in range(len(s)):
    print(s[i])
```

Yöntem 2:

```python
s = 'hello'
for elem in s:
    print(elem)
```

### String Metotları

Python'da string üzerinde işlem yapmak için string tipinin kendi metotlarını kullanabiliriz. Diyelim ki `foo` adında bir string ve string'in `bar` adında bir metodu var; o zaman string metodunu kullanmanın sözdizimi `foo.bar()` biçimindedir; bu, nesne referansı üzerinden nesnenin metodunu çağırma sözdizimidir ve daha önce liste metotlarını kullanırkenki sözdizimiyle aynıdır.

#### Büyük/Küçük Harf İşlemleri

Aşağıdaki kod, string büyük/küçük harf dönüşümüyle ilgili metotları gösterir.

```python
s1 = 'hello, world!'
# String'in ilk harfini büyüt
print(s1.capitalize())  # Hello, world!
# Her kelimenin ilk harfini büyüt
print(s1.title())       # Hello, World!
# String'i tamamen büyüt
print(s1.upper())       # HELLO, WORLD!
s2 = 'GOODBYE'
# String'i tamamen küçült
print(s2.lower())       # goodbye
# s1 ve s2'nin değerlerini kontrol et
print(s1)               # hello, world
print(s2)               # GOODBYE
```

> **Not**: String değiştirilemez bir tip olduğundan, string metotlarıyla yapılan işlemler yeni bir string üretir; ancak asıl değişkenin değeri değişmez. Bu yüzden yukarıdaki kodda son olarak `s1` ve `s2` değişkenlerinin değerlerini kontrol ettiğimizde, değerlerinin değişmediğini görürüz.

#### Arama İşlemleri

Bir string içinde başka bir string'i baştan sona aramak istiyorsanız `find` veya `index` metodunu kullanabilirsiniz. `find` ve `index` metotlarını kullanırken, metodun parametreleriyle arama aralığını da belirleyebilirsiniz; yani arama `0` indeksinden başlamak zorunda değildir.

```python
s = 'hello, world!'
print(s.find('or'))      # 8
print(s.find('or', 9))   # -1
print(s.find('of'))      # -1
print(s.index('or'))     # 8
print(s.index('or', 9))  # ValueError: substring not found
```

>**Not**: `find` metodu belirtilen string'i bulamazsa `-1` döndürür; `index` metodu ise bulamazsa `ValueError` hatası üretir.

`find` ve `index` metotlarının ters yönlü arama (sondan başa) sürümleri de vardır: `rfind` ve `rindex`; kod aşağıdaki gibidir.

```python
s = 'hello world!'
print(s.find('o'))       # 4
print(s.rfind('o'))      # 7
print(s.rindex('o'))     # 7
# print(s.rindex('o', 8))  # ValueError: substring not found
```

#### Özellik Kontrolü

String'in `startswith` ve `endswith` metotlarıyla, string'in belirli bir string'le başlayıp başlamadığını ve bitip bitmediğini belirleyebiliriz; ayrıca `is` ile başlayan metotlarla string'in özellikleri kontrol edilebilir; bu metotlar mantıksal değer döndürür; kod aşağıdaki gibidir.

```python
s1 = 'hello, world!'
print(s1.startswith('He'))   # False
print(s1.startswith('hel'))  # True
print(s1.endswith('!'))      # True
s2 = 'abc123456'
print(s2.isdigit())  # False
print(s2.isalpha())  # False
print(s2.isalnum())  # True
```

> **Not**: Yukarıdaki `isdigit`, string'in tamamen rakamlardan oluşup oluşmadığını; `isalpha`, string'in tamamen harflerden oluşup oluşmadığını belirler (buradaki harf Unicode karakterleri ifade eder ama Emoji karakterlerini içermez); `isalnum` ise string'in harf ve rakamlardan oluşup oluşmadığını belirler.

#### Biçimlendirme

Python'da string tipi; `center`, `ljust` ve `rjust` metotlarıyla ortalanabilir, sola ve sağa hizalanabilir. String'in soluna sıfır eklemek için `zfill` metodu da kullanılabilir.

```python
s = 'hello, world'
print(s.center(20, '*'))  # ****hello, world****
print(s.rjust(20))        #         hello, world
print(s.ljust(20, '~'))   # hello, world~~~~~~~~
print('33'.zfill(5))      # 00033
print('-33'.zfill(5))     # -0033
```

Daha önce anlattığımız gibi, `print` fonksiyonuyla string yazdırırken aşağıdaki yöntemle string biçimlendirilebilir.

```python
a = 321
b = 123
print('%d * %d = %d' % (a, b, a * b))
```

Elbette string biçimlendirmeyi string'in `format` metoduyla da yapabiliriz; kod aşağıdaki gibidir.

```python
a = 321
b = 123
print('{0} * {1} = {2}'.format(a, b, a * b))
```

Python 3.6'dan itibaren biçimlendirilmiş string için daha da sade bir yazım vardır: string'in önüne `f` koyarak string'i biçimlendirmek. `f` ile başlayan string'lerde `{değişken adı}` bir yer tutucudur ve değişkenin karşılık gelen değeriyle değiştirilir; kod aşağıdaki gibidir.

```python
a = 321
b = 123
print(f'{a} * {b} = {a * b}')
```

Biçimlendirme sözdiziminde değişken değerinin biçimini daha fazla kontrol etmeniz gerekirse, aşağıdaki tabloya bakarak string biçimlendirme işlemi yapabilirsiniz.

| Değişken değeri      | Yer tutucu     | Biçimlenmiş sonuç    | Açıklama |
| ----------- | ---------- | ------------- | ---- |
| `3.1415926` | `{:.2f}`   | `'3.14'`      | Ondalıktan sonra iki basamak tut |
| `3.1415926` | `{:+.2f}`  | `'+3.14'`       | İşaretle birlikte ondalıktan sonra iki basamak |
| `-1`        | `{:+.2f}`  | `'-1.00'` | İşaretle birlikte ondalıktan sonra iki basamak |
| `3.1415926` | `{:.0f}`   | `'3'` | Ondalık yok |
| `123`       | `{:0>10d}` | `'0000000123'` | Sola `0` ekle, 10 basamağa tamamla |
| `123`       | `{:x<10d}` | `'123xxxxxxx'` | Sağa `x` ekle, 10 basamağa tamamla |
| `123`       | `{:>10d}`  | `'       123'` | Sola boşluk ekle, 10 basamağa tamamla |
| `123`       | `{:<10d}` | `'123       '` | Sağa boşluk ekle, 10 basamağa tamamla |
| `123456789` | `{:,}`     | `'123,456,789'` | Virgülle ayrılmış biçim |
| `0.123`     | `{:.2%}`   | `'12.30%'`    | Yüzde biçimi |
| `123456789` | `{:.2e}`   | `'1.23e+08'`  | Bilimsel gösterim |

#### Kırpma İşlemleri

String'in `strip` metodu, string'in sol ve sağ ucundaki belirtilen karakterleri kırpıp bize yeni bir string verir; varsayılan olarak boşluk karakterini kırpar. Bu metot çok pratik değere sahiptir; kullanıcının girdi sırasında yanlışlıkla yazdığı baş/son boşluklarını temizlemek için kullanılabilir. `strip` metodunun `lstrip` ve `rstrip` adlı iki sürümü de vardır; adlarından bu iki metodun ne işe yaradığını tahmin edebilirsiniz.

```python
s1 = '   jackfrued@126.com  '
print(s1.strip())      # jackfrued@126.com
s2 = '~Merhaba, dünya~'
print(s2.lstrip('~'))  # Merhaba, dünya~
print(s2.rstrip('~'))  # ~Merhaba, dünya
```

#### Değiştirme İşlemleri

String'deki belirtilen içeriği yeni içerikle değiştirmek istiyorsanız `replace` metodunu kullanabilirsiniz; kod aşağıdaki gibidir. `replace` metodunun ilk parametresi değiştirilecek içerik, ikinci parametresi değiştirilen içeriktir; üçüncü parametreyle değiştirme sayısı da belirtilebilir.

```python
s = 'hello, good world'
print(s.replace('o', '@'))     # hell@, g@@d w@rld
print(s.replace('o', '@', 1))  # hell@, good world
```

#### Ayırma ve Birleştirme

String'in `split` metoduyla bir string'i birden çok string'e ayırabilir (bir listede saklanır), `join` metoduyla da listedeki birden çok string'i tek bir string'e bağlayabiliriz; kod aşağıdaki gibidir.

```python
s = 'I love you'
words = s.split()
print(words)            # ['I', 'love', 'you']
print('~'.join(words))  # I~love~you
```

Belirtmek gerekir ki `split` metodu varsayılan olarak boşlukla ayırır; string'i ayırmak için başka karakterler de belirtebilir, ayrıca en fazla ayırma sayısını belirterek ayırma etkisini kontrol edebiliriz; kod aşağıdaki gibidir.

```python
s = 'I#love#you#so#much'
words = s.split('#')
print(words)  # ['I', 'love', 'you', 'so', 'much']
words = s.split('#', 2)
print(words)  # ['I', 'love', 'you#so#much']
```

#### Kodlama ve Kod Çözme

Python'da string `str` tipinin yanı sıra, ikili veriyi temsil eden **bayt dizisi** (`bytes`) tipi de vardır. Bayt dizisi, **sıfır veya daha fazla bayttan oluşan sonlu bir dizidir**. String'in `encode` metoduyla string'i belirli bir kodlama biçimine göre bayt dizisine kodlayabilir; bayt dizisinin `decode` metoduyla da bayt dizisini string'e çözebiliriz; kod aşağıdaki gibidir.

```python
a = '骆昊'
b = a.encode('utf-8')
c = a.encode('gbk')
print(b)                  # b'\xe9\xaa\x86\xe6\x98\x8a'
print(c)                  # b'\xc2\xe6\xea\xbb'
print(b.decode('utf-8'))  # 骆昊
print(c.decode('gbk'))    # 骆昊
```

Dikkat: kodlama ve kod çözme biçimleri tutarlı değilse, bozuk karakter sorununa (asıl içeriğin yeniden üretilememesi) yol açar veya `UnicodeDecodeError` hatası üretip programın çökmesine neden olur.

#### Diğer Metotlar

String tipi için sık kullanılan bir başka işlem de örüntü eşleştirme kontrolüdür; yani string'in belirli bir kalıba uyup uymadığını kontrol etmek. Örneğin bir web sitesinin, kullanıcı kayıt bilgilerindeki kullanıcı adı ve e-postayı kontrol etmesi bir örüntü eşleştirme kontrolüdür. Örüntü eşleştirme kontrolü yapan araca **düzenli ifade** (regular expression) denir; Python dili, standart kütüphanedeki `re` modülüyle düzenli ifade desteği sunar; bu bilgiyi ileriki derslerde anlatacağız.

### Özet

String'i nasıl temsil edeceğini ve işleyeceğini bilmek programcılar için çok önemlidir; çünkü sık sık metin bilgisi işleriz. Python'da string üzerinde işlem yapmak için birleştirme, indeksleme, dilimleme gibi operatörleri kullanabileceğiniz gibi, string tipinin sunduğu çok zengin metotları da kullanabilirsiniz.
