## Fonksiyonların İleri Uygulamaları

> **Translated to Turkish by** himmetcanumutlu

Bir önceki bölümde Python'daki yüksek dereceli fonksiyonları keşfettik; fonksiyonların tanımı ve uygulaması hakkında daha derin bir kavrayışa sahip olduğunuza inanıyorum. Bu bölümde fonksiyonla ilgili bilgileri anlatmaya devam ediyoruz: biri Python'a özgü **dekoratör** sözdizimi, diğeri fonksiyonun **özyinelemeli çağrısı**.

### Dekoratörler

Python dilinde dekoratör, "**bir fonksiyonu başka bir fonksiyonla süsleyip ona ek yetenek kazandırmak**" anlamına gelen bir sözdizimi olgusudur. Dekoratörün kendisi bir fonksiyondur; parametresi süslenen fonksiyon, dönüş değeri ise süsleme işlevine sahip bir fonksiyondur. Bu açıklamadan da anlaşılacağı gibi, dekoratör bir yüksek dereceli fonksiyondur; parametresi de dönüş değeri de fonksiyondur. Yine de dekoratör kavramı, programlama diline yeni başlayanlar için baş ağrıtıcıdır. Önce basit bir örnekle dekoratörün ne işe yaradığını açıklayalım. `download` ve `upload` adında, sırasıyla dosya indirme ve yükleme yapan iki fonksiyon olduğunu varsayalım; aşağıdaki gibidir.

```python
import random
import time


def download(filename):
    """Dosyayı indir"""
    print(f'{filename} indirilmeye başlandı.')
    time.sleep(random.random() * 6)
    print(f'{filename} indirme tamamlandı.')

    
def upload(filename):
    """Dosyayı yükle"""
    print(f'{filename} yüklenmeye başlandı.')
    time.sleep(random.random() * 8)
    print(f'{filename} yükleme tamamlandı.')

    
download('MySQL silmekten kaçmaya.avi')
upload("Python'a başlamaktan hastanelik olmaya.pdf")
```

> **Not**: Yukarıdaki kod, dosya indirme ve yüklemenin belirli bir süre almasını, rastgele bir süre uyuyarak simüle eder; gerçekten internetten indirme/yükleme yapmaz. Python diliyle internetten dosya indirip yüklemek de çok basittir; ileride anlatacağız.

Şimdi yeni bir gereksinim var: `download` ve `upload` fonksiyonlarını çağırıp dosya indirip yüklemenin tam olarak ne kadar sürdüğünü öğrenmek istiyoruz; bunu nasıl yaparız? Birçok arkadaşın aklına gelmiştir: fonksiyon çalışmaya başladığında bir zaman kaydeder, fonksiyon çağrısı bittiğinde bir zaman daha kaydeder, iki zamanı çıkarıp indirme veya yükleme süresini hesaplarız; kod aşağıdaki gibidir.

```python
start = time.time()
download('MySQL silmekten kaçmaya.avi')
end = time.time()
print(f'Geçen süre: {end - start:.2f} saniye')
start = time.time()
upload("Python'a başlamaktan hastanelik olmaya.pdf")
end = time.time()
print(f'Geçen süre: {end - start:.2f} saniye')
```

Yukarıdaki kodla dosya indirirken ve yüklerken harcanan süreyi kaydedebiliriz; ancak fark ettiniz mi, yukarıdaki zaman kaydetme, süre hesaplama ve gösterme kodları yinelenen kodlardır. Programlama deneyimi olanlar bilir ki **yinelenen kod tüm kötülüklerin anasıdır**. Peki yinelenen kod yazmadan, basit ve zarif bir yöntemle fonksiyonun çalışma süresini kaydetmenin bir yolu yok mu? Python dilinde dekoratör, bu tür sorunları çözmenin en iyi seçeneğidir. Dekoratör sözdizimiyle, asıl işle (yükleme ve indirme) ilgisi olmayan süre tutma kodunu tek bir fonksiyona kapsülleyebiliriz. `upload` ve `download` fonksiyonlarının süre tutması gerekiyorsa, dekoratörü doğrudan bu iki fonksiyona uygularız. Yukarıda da söylediğimiz gibi dekoratör bir yüksek dereceli fonksiyondur; parametresi de dönüş değeri de fonksiyondur. Süre tutan dekoratörü şimdilik `record_time` olarak adlandıralım; genel yapısı aşağıdaki kod gibi olmalıdır.

```python
def record_time(func):
    
    def wrapper(*args, **kwargs):
        
        result = func(*args, **kwargs)
        
        return result
    
    return wrapper
```

Fark etmişsinizdir ki `record_time` fonksiyonunun `func` parametresi süslenen fonksiyonu temsil eder; fonksiyonun içinde tanımlanan `wrapper` fonksiyonu ise süsleme işlevine sahip fonksiyondur; süslenen `func` fonksiyonunu çalıştırır ve sonunda fonksiyonun ürettiği dönüş değerini döndürmesi gerekir. Fark ettiniz mi bilmem, yukarıdaki kodda 4. ve 6. satırlarda iki boş satır bıraktım; bu, ek işlev eklemek için bu yerlere kod koyabileceğimiz anlamına gelir. `record_time` fonksiyonu sonunda süsleme işlevine sahip `wrapper` fonksiyonunu döndürür ve onunla asıl `func` fonksiyonunu değiştirir. Asıl `func` fonksiyonu `record_time` ile süslendiğinde, onu çağırdığımızda aslında `wrapper` fonksiyonunu çağırırız; ek yetenek bu yüzden elde edilir. `wrapper` fonksiyonunun parametreleri özeldir; `wrapper` ile asıl `func` fonksiyonunu değiştireceğimiz ama `func` fonksiyonunun hangi parametreleri alacağını bilmediğimiz için, değişken parametre ve anahtar sözcük parametreleriyle hepsini olduğu gibi kabul ederiz; sonra `func`'ı çağırırken aynen geri veririz. Ayrıca vurgulamak gerekir ki Python dili fonksiyonların iç içe tanımlanmasını destekler; yukarıdaki gibi `record_time` fonksiyonu içinde `wrapper` fonksiyonunu tanımlayabiliriz; bu işlem birçok programlama dilinde desteklenmez.

Bu yapıyı anladıktan sonra süre tutma işlevini bu dekoratöre yazabiliriz; kod aşağıdaki gibidir.

```python
import time


def record_time(func):

    def wrapper(*args, **kwargs):
        # Süslenen fonksiyonu çalıştırmadan önce başlangıç zamanını kaydet
        start = time.time()
        # Süslenen fonksiyonu çalıştır ve dönüş değerini al
        result = func(*args, **kwargs)
        # Süslenen fonksiyon çalıştıktan sonra bitiş zamanını kaydet
        end = time.time()
        # Süslenen fonksiyonun çalışma süresini hesapla ve göster
        print(f'{func.__name__} çalışma süresi: {end - start:.2f} saniye')
        # Süslenen fonksiyonun dönüş değerini döndür
        return result
    
    return wrapper
```

Dekoratör yazmak epey uğraştırıcı olsa da, bir kez yazınca sürekli kullanılan pratik bir işlemdir; ileride yine fonksiyon çalışma süresini kaydetme ihtiyacı olursa yalnızca yukarıdaki dekoratörü eklememiz yeterlidir. Yukarıdaki dekoratör fonksiyonunu kullanmanın iki yolu vardır. İlk yol, dekoratör fonksiyonunu doğrudan çağırıp süslenen fonksiyonu geçerek dönüş değerini almaktır; bu dönüş değeriyle asıl fonksiyonu doğrudan değiştirebiliriz; böylece çağırırken dekoratörün sağladığı ek yeteneği (çalışma süresi kaydı) elde etmiş oluruz; aşağıdaki kodu deneyince anlarsınız.

```python
download = record_time(download)
upload = record_time(upload)
download('MySQL silmekten kaçmaya.avi')
upload("Python'a başlamaktan hastanelik olmaya.pdf")
```

Python'da dekoratörü kullanmanın daha pratik bir yolu da **sözdizimsel şeker** (syntactic sugar) kullanmaktır. Sözdizimsel şeker, programlama diline eklenen, dilin işlevini etkilemeyen ama kullanımı daha pratik hale getiren ve kodun okunabilirliğini artıran bir sözdizimidir. `@dekoratör fonksiyonu` ile dekoratör fonksiyonunu doğrudan süslenen fonksiyonun üzerine koyabiliriz; etkisi yukarıdaki kodla aynıdır. Tam kodu aşağıya koyuyoruz; dekoratörü nasıl tanımlayıp kullandığımıza tekrar bakabilirsiniz.

```python
import random
import time


def record_time(func):

    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        end = time.time()
        print(f'{func.__name__} çalışma süresi: {end - start:.2f} saniye')
        return result

    return wrapper


@record_time
def download(filename):
    print(f'{filename} indirilmeye başlandı.')
    time.sleep(random.random() * 6)
    print(f'{filename} indirme tamamlandı.')


@record_time
def upload(filename):
    print(f'{filename} yüklenmeye başlandı.')
    time.sleep(random.random() * 8)
    print(f'{filename} yükleme tamamlandı.')


download('MySQL silmekten kaçmaya.avi')
upload("Python'a başlamaktan hastanelik olmaya.pdf")
```

Yukarıdaki kodda dekoratör sözdizimsel şekeriyle `download` ve `upload` fonksiyonlarına dekoratör ekledik; süslenen `download` ve `upload` fonksiyonları aslında dekoratörde döndürdüğümüz `wrapper` fonksiyonudur; onları çağırmak aslında `wrapper` fonksiyonunu çağırmaktır; fonksiyon çalışma süresini kaydetme işlevi bu yüzden oluşur.

Kodun bazı yerlerinde dekoratörün etkisini kaldırıp asıl fonksiyonu çalıştırmak istiyorsak, dekoratör fonksiyonunu tanımlarken küçük bir ek iş yapmamız gerekir. Python standart kütüphanesi `functools` modülünün `wraps` fonksiyonu da bir dekoratördür; onu `wrapper` fonksiyonunun üzerine koyarız; bu dekoratör, süslenmeden önceki fonksiyonu korumamıza yardımcı olur; böylece dekoratörü iptal etmek gerektiğinde, süslenen fonksiyonun `__wrapped__` özniteliğiyle süslenmeden önceki fonksiyona ulaşılabilir.

```python
import random
import time

from functools import wraps


def record_time(func):

    @wraps(func)
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        end = time.time()
        print(f'{func.__name__} çalışma süresi: {end - start:.2f} saniye')
        return result

    return wrapper


@record_time
def download(filename):
    print(f'{filename} indirilmeye başlandı.')
    time.sleep(random.random() * 6)
    print(f'{filename} indirme tamamlandı.')


@record_time
def upload(filename):
    print(f'{filename} yüklenmeye başlandı.')
    time.sleep(random.random() * 8)
    print(f'{filename} yükleme tamamlandı.')


# Süslü fonksiyonu çağırmak çalışma süresini kaydeder
download('MySQL silmekten kaçmaya.avi')
upload("Python'a başlamaktan hastanelik olmaya.pdf")
# Dekoratörün etkisini kaldırıp çalışma süresini kaydetme
download.__wrapped__('MySQL bilinmesi gerekenler.pdf')
upload.__wrapped__("Python'da acemiden ustaya.pdf")
```

**Dekoratör fonksiyonunun kendisi de parametrelendirilebilir**; basitçe söylemek gerekirse dekoratör, çağıranın geçtiği parametrelerle de özelleştirilebilir; bu bilgiyi kullanacağımız yerde anlatacağız.

### Özyinelemeli Çağrı

Python'da fonksiyonların iç içe tanımlanmasına ve fonksiyonların birbirini çağırmasına izin verilir; ayrıca bir fonksiyon doğrudan ya da dolaylı olarak kendini çağırabilir. Fonksiyonun kendini çağırmasına **özyinelemeli çağrı** denir; peki özyinelemeli çağrı ne işe yarar? Gerçekte birçok sorunun tanımı zaten özyinelemeli bir tanımdır; örneğin daha önce anlattığımız faktöriyel. Negatif olmayan `N` tam sayısının faktöriyeli, `N` çarpı `N-1`'in faktöriyelidir; yani $\small{N! = N \times (N-1)!}$. Tanımın hem solunda hem sağında faktöriyel kavramı geçer; bu yüzden bu özyinelemeli bir tanımdır. O halde faktöriyel hesaplayan fonksiyonu özyinelemeli çağrıyla yazabiliriz; kod aşağıdaki gibidir.

```python
def fac(num):
    if num in (0, 1):
        return 1
    return num * fac(num - 1)
```

Yukarıdaki kodda `fac` fonksiyonu içinde yine `fac` fonksiyonu çağrılır; bu, özyinelemeli çağrıdır. Kodun 2. satırındaki `if` koşuluna **özyinelemenin yakınsama koşulu** denir; basitçe söylemek gerekirse fonksiyonun özyinelemeli çağrısının ne zaman biteceğini belirler. Faktöriyel hesaplanırken `0` veya `1`'in faktöriyeline gelinince özyinelemeli çağrı durur, doğrudan `1` döndürülür. Kodun 4. satırındaki `num * fac(num - 1)` ise **özyineleme formülüdür**, yani faktöriyelin özyinelemeli tanımıdır. Şimdi basitçe analiz edelim: `fac(5)` ile `5`'in faktöriyelini hesaplarsak süreç nasıl işler?

```python
# Özyinelemeli çağrı fonksiyonları yığına girer
# 5 * fac(4)
# 5 * (4 * fac(3))
# 5 * (4 * (3 * fac(2)))
# 5 * (4 * (3 * (2 * fac(1))))
# Özyineleme durur, fonksiyonlar yığından çıkar
# 5 * (4 * (3 * (2 * 1)))
# 5 * (4 * (3 * 2))
# 5 * (4 * 6)
# 5 * 24
# 120
print(fac(5))    # 120
```

Dikkat: Fonksiyon çağrısı, bellekte "yığın" (stack) adı verilen bir veri yapısıyla mevcut kodun çalışma ortamını saklar; fonksiyon çağrısı bittikten sonra bu yığın yapısıyla önceki çalışma ortamı geri yüklenir. Yığın, ilk giren son çıkar (LIFO) prensibine sahip bir veri yapısıdır; bu, en erken yığına giren fonksiyonun en son döneceği, en son giren fonksiyonun ise en önce döneceği anlamına gelir. Örneğin `a` adında bir fonksiyon çağırılsın; `a` fonksiyonunun gövdesinde `b` fonksiyonu, `b`'nin gövdesinde de `c` fonksiyonu çağrılsın; o zaman yığına ilk giren `a`, yığından ilk çıkan ise `c`'dir. Her fonksiyon çağrısına girildiğinde yığına bir **yığın çerçevesi** (stack frame) eklenir; yığın çerçevesi, az önce sözünü ettiğimiz mevcut kodun çalışma ortamını saklayan yapıdır; her fonksiyon çağrısı bittiğinde yığından bir yığın çerçevesi eksilir. Genellikle bellekteki yığın alanı çok küçüktür; bu yüzden özyinelemeli çağrı sayısı çok fazla olursa **yığın taşması** (stack overflow) oluşur. Bu nedenle **özyinelemeli çağrının hızla yakınsadığından emin olunmalıdır**. `fac(5000)` çalıştırmayı deneyip `RecursionError` hatası alıp almadığınıza bakın; hata mesajı `maximum recursion depth exceeded in comparison` (karşılaştırmada maksimum özyineleme derinliği aşıldı) şeklindedir; aslında gerçekleşen şey yığın taşmasıdır.

Resmî Python yorumlayıcısını (CPython) kullanırsak, fonksiyon çağrısı yığın yapısının maksimum derinliği varsayılan olarak `1000` katmandır. Bu derinlik aşılırsa yukarıda sözünü ettiğimiz `RecursionError` oluşur. Elbette `sys` modülünün `setrecursionlimit` fonksiyonuyla özyinelemeli çağrının maksimum derinliğini değiştirebiliriz; ancak bunu önermiyoruz; çünkü yapmamız gereken özyinelemenin hızla yakınsamasını sağlamaktır; aksi takdirde özyineleme yerine döngüyle yinelemeyi düşünmeliyiz.

Daha önce anlattığımız Fibonacci dizisi üretme örneğini tekrar ele alalım; Fibonacci dizisinin ilk iki sayısı `1`'dir; üçüncü sayıdan itibaren her sayı önceki iki sayının toplamıdır; `f(n) = f(n - 1) + f(n - 2)` olarak yazılabilir; açıkça bu da özyinelemeli bir tanımdır. Bu yüzden n'inci Fibonacci sayısını hesaplamak için aşağıdaki özyinelemeli çağrı fonksiyonunu kullanabiliriz.

```python
def fib1(n):
    if n in (1, 2):
        return 1
    return fib1(n - 1) + fib1(n - 2)


for i in range(1, 21):
    print(fib1(i))
```

Hatırlatmak isteriz ki yukarıdaki Fibonacci sayısı hesaplama kodu çok sade ve anlaşılır görünse de, çalışma performansı oldukça kötüdür. Deneyebilirsiniz: yukarıdaki koddaki `for` döngüsündeki `range` fonksiyonunun ikinci parametresini `51` yapıp, yani ilk 50 Fibonacci sayısını yazdırıp ne kadar sürdüğüne bakın; kodunuzun çalışma süresini yorum bölümünde paylaşabilirsiniz. Neden bu kadar yavaş olduğunu kendiniz düşünebilirsiniz. Açıkça, Fibonacci dizisini doğrudan döngüyle yineleyerek elde etmek daha iyi bir seçimdir; kod aşağıdaki gibidir.

```python
def fib2(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```

Bunun dışında, yukarıdaki özyinelemeli kodu optimize etmek için Python standart kütüphanesi `functools` modülünün `lru_cache` fonksiyonunu da kullanabiliriz. `lru_cache` fonksiyonu bir dekoratör fonksiyonudur; onu yukarıdaki `fib1` fonksiyonunun üzerine koyarız; bu dekoratör, fonksiyonun çalışma sonucunu önbelleğe alarak özyinelemeli çağrı sürecindeki çok sayıda yinelenen hesaplamayı önler; böylece kodun çalışma performansı "uçar gibi" artar. İlk 50 Fibonacci sayısını yazdırıp, dekoratörü ekledikten sonra kodun ne kadar sürdüğüne bakabilirsiniz; yorumlarda buluşalım!

```python
from functools import lru_cache


@lru_cache()
def fib1(n):
    if n in (1, 2):
        return 1
    return fib1(n - 1) + fib1(n - 2)


for i in range(1, 51):
    print(i, fib1(i))
```

> **İpucu**: `lru_cache` fonksiyonu parametre alan bir dekoratördür; bu yüzden yukarıdaki 4. satırda dekoratör sözdizimsel şekerini kullanırken `lru_cache`'ten sonra parantez koymak gerekir. `lru_cache` fonksiyonunun `maxsize` adında çok önemli bir parametresi vardır; önbellek alanının boyutunu tanımlamak için kullanılır, varsayılan değeri 128'dir.

###  Özet

Dekoratör, Python diline özgü bir sözdizimidir; **mevcut fonksiyonları güçlendirmek için dekoratör kullanılabilir**; bu, çok kullanışlı bir programlama tekniğidir. Öte yandan, fonksiyonun özyinelemeli çağrısıyla bazı karmaşık sorunlar kod düzeyinde basitleştirilebilir; ancak **özyinelemeli çağrıda yakınsama koşuluna ve özyineleme formülüne dikkat edilmelidir**. Özyineleme formülünü bulunca özyinelemeli çağrıyı kullanma şansınız olur; yakınsama koşulu ise özyinelemeli çağrının durabilmesini sağlar. Fonksiyon çağrısı, bellekteki yığın alanıyla çalışma ortamını saklar ve geri yükler; yığın alanı genellikle çok küçüktür; bu yüzden **özyineleme hızla yakınsamazsa yığın taşması hatası oluşup programın çökmesine neden olabilir**.
