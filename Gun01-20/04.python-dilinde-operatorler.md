##  Python Dilinde Operatörler

> **Translated to Turkish by** himmetcanumutlu

Python dili birçok operatörü destekler. Aşağıdaki tablo, Python'daki operatörleri öncelik sırasına göre (yüksekten düşüğe) listeler. Değişkenler ve operatörler elimizde olduğunda, gerçek sorunları çözmek için çeşitli ifadeler kurabiliriz. Bilgisayar biliminde **ifade (expression), bir veya daha fazla sabit, değişken, fonksiyon ve operatörden oluşan; programlama dilinin yorumlayıp hesaplayarak başka bir değer üretebildiği sözdizimsel bir varlıktır**. Bu tanımı anlamadıysanız sorun değil; ama şunu mutlaka bilmelisiniz: hangi programlama dilini kullanırsanız kullanın, ifade kurmak çok önemlidir.

| Operatör                                                       | Açıklama                           |
| ------------------------------------------------------------ | ------------------------------ |
| `[]`, `[:]`                                                 | İndeksleme, dilimleme                  |
| `**`                                                         | Üs alma                             |
| `~`, `+`, `-`                                              | Bitsel değil (tümleme), artı işareti, eksi işareti         |
| `*`, `/`, `%`, `//`                                       | Çarpma, bölme, mod (kalan), tam bölme            |
| `+`, `-`                                                    | Toplama, çıkarma                        |
| `>>`, `<<`                                                  | Sağa kaydırma, sola kaydırma                    |
| `&`                                                          | Bitsel ve                         |
| `^`, `|`                                                   | Bitsel özel veya (XOR), bitsel veya              |
| `<=`, `<`, `>`, `>=`                                      | Küçük eşit, küçük, büyük, büyük eşit |
| `==`, `!=`                                                   | Eşit, eşit değil                  |
| `is`, `is not`                                               | Kimlik operatörleri                     |
| `in`, `not in`                                                | Üyelik operatörleri                     |
| `not`, `or`, `and`                                             | Mantıksal operatörler                     |
| `=`, `+=`, `-=`, `*=`, `/=`, `%=`, `//=`, `**=`, `&=`, `\|=`, `^=`, `>>=`, `<<=` | Atama operatörleri             |

>**Not**: Öncelik, bir ifadede birden çok operatör bulunduğunda hangisinin önce yürütüleceğini belirleyen sıradır. Kod yazarken bir ifadedeki operatörlerin önceliğinden emin değilseniz, işlem sırasını garanti altına almak için parantez kullanabilirsiniz.

### Aritmetik Operatörler

Python'daki aritmetik operatörler oldukça zengindir; herkesin çok iyi bildiği toplama, çıkarma, çarpma ve bölmenin yanı sıra tam bölme operatörü, mod (kalan bulma) operatörü ve üs alma operatörü de vardır. Aşağıdaki örnek aritmetik operatörlerin kullanımını gösterir.

```python
"""
Aritmetik operatörler

Version: 1.0
Author: 骆昊 (jackfrued)
"""
print(321 + 12)     # toplama işlemi, çıktı 333
print(321 - 12)     # çıkarma işlemi, çıktı 309
print(321 * 12)     # çarpma işlemi, çıktı 3852
print(321 / 12)     # bölme işlemi, çıktı 26.75
print(321 // 12)    # tam bölme işlemi, çıktı 26
print(321 % 12)     # mod işlemi, çıktı 9
print(321 ** 12)    # üs alma işlemi, çıktı 1196906950228928915420617322241
```

Aritmetik işlemlerde önce çarpma-bölme, sonra toplama-çıkarma yapılır; bu, matematik derslerindeki bilgiyle aynıdır; yani çarpma ve bölmenin önceliği toplama ve çıkarmadan yüksektir. Üs alma işlemi varsa, üs almanın önceliği çarpma-bölmeden de yüksektir. Aritmetik işlemlerin sırasını değiştirmek isterseniz, İngilizce giriş modunda parantez kullanabilirsiniz; parantez içindeki ifade önce yürütülür. Aşağıdaki örneğe bakın.

```python
"""
Aritmetik işlemlerin önceliği

Version: 1.0
Author: 骆昊 (jackfrued)
"""
print(2 + 3 * 5)           # 17
print((2 + 3) * 5)         # 25
print((2 + 3) * 5 ** 2)    # 125
print(((2 + 3) * 5) ** 2)  # 625
```

### Atama Operatörleri

Atama operatörü muhtemelen en yaygın operatördür; görevi, sağdaki değeri soldaki değişkene atamaktır. Atama operatörü yukarıdaki aritmetik operatörlerle birleştirilerek bileşik atama operatörleri oluşturulabilir; örneğin `a += b`, `a = a + b`'ye denktir; `a *= a + 2`, `a = a * (a + 2)`'ye denktir. Aşağıdaki örnek, atama ve bileşik atama operatörlerinin kullanımını gösterir.

```python
"""
Atama operatörleri ve bileşik atama operatörleri

Version: 1.0
Author: 骆昊 (jackfrued)
"""
a = 10
b = 3
a += b        # şuna denk: a = a + b
a *= a + 2    # şuna denk: a = a * (a + 2)
print(a)      # burada ne çıkacağını siz hesaplayın
```

Atama işleminin oluşturduğu ifadenin kendisi hiçbir değer üretmez; yani bir atama ifadesini `print` fonksiyonuna koyup değerini yazdırmaya çalışırsanız sözdizimi hatası alırsınız. Bu sorunu çözmek için Python 3.8'de `:=` adında yeni bir atama operatörü eklendi; buna "mors (walrus) operatörü" denir; neden bu adı aldığını tahmin edebilirsiniz. Mors operatörü de sağdaki değeri soldaki değişkene atar; ancak normal atama operatöründen farkı, sağdaki değerin aynı zamanda tüm ifadenin değeri olmasıdır. Aşağıdaki koda bakınca anlayacaksınız.

```python
"""
Mors operatörü

Version: 1.0
Author: 骆昊 (jackfrued)
"""
# SyntaxError: invalid syntax
# print((a = 10))
# mors operatörü
print((a := 10))  # 10
print(a)          # 10
```

> **İpucu**: Yukarıdaki 8. satırdaki kodu yorumdan çıkarırsanız, çalıştırınca `SyntaxError: invalid syntax` hatası görürsünüz. Dikkat edin, bu satırda `a = 10` ifadesini parantez içine aldık; yanlışlıkla `print(a = 10)` yazarsanız `TypeError: 'a' is an invalid keyword argument for print()` hatası görürsünüz. Fonksiyonları anlattığımızda bu hata mesajının ne anlama geldiğini anlayacaksınız.

### Karşılaştırma ve Mantıksal Operatörler

Karşılaştırma operatörlerine ilişkisel operatörler de denir; `==`, `!=`, `<`, `>`, `<=`, `>=` operatörlerini içerir; bakınca hemen anlarsınız. Dikkat etmeniz gereken nokta, eşitlik karşılaştırmasında `==` kullanıldığıdır; burada iki eşittir işareti vardır, çünkü `=` atama operatörüdür (az önce anlattık). Eşit değillik karşılaştırmasında `!=` kullanılır; bu, matematikteki $\small{\neq}$ sembolünden farklıdır. Python 2'de eşit değil için `<>` kullanılmıştı; Python 3'te `<>` kullanmak `SyntaxError` (sözdizimi hatası) üretir. Karşılaştırma operatörleri mantıksal değer üretir; sonuç ya `True` ya da `False`'dır.

Üç mantıksal operatör vardır: `and`, `or` ve `not`. `and` kelime anlamıyla "ve"dir; bu nedenle `and` operatörü iki mantıksal değeri veya mantıksal değer üreten ifadeyi birleştirir. İki taraftaki mantıksal değer de `True` ise sonuç `True` olur; iki taraftan biri `False` ise sonuç `False` olur. Elbette `and` operatörünün solundaki değer `False` ise, sağdaki değer ne olursa olsun sonuç `False`'dır; bu durumda sağdaki değer atlanır (profesyonel terimle buna "kısa devre" denir; `and`'in sağı bir ifadeyse o ifade çalıştırılmaz). `or` kelime anlamıyla "veya"dır; bu nedenle `or` operatörü de iki mantıksal değeri veya mantıksal değer üreten ifadeyi birleştirir. İki taraftan herhangi biri `True` ise sonuç `True` olur. Elbette `or` operatörünün de kısa devre özelliği vardır; solundaki değer `True` olduğunda sağdaki değer kısa devreye uğrar (sağı bir ifadeyse o ifade çalıştırılmaz). `not` operatörünün arkasına bir mantıksal değer gelebilir; `not`'un arkasındaki değer veya ifade `True` ise sonuç `False`, `False` ise sonuç `True` olur.

```python
"""
Karşılaştırma ve mantıksal operatörlerin kullanımı

Version: 1.0
Author: 骆昊 (jackfrued)
"""
flag0 = 1 == 1
flag1 = 3 > 2
flag2 = 2 < 1
flag3 = flag1 and flag2
flag4 = flag1 or flag2
flag5 = not flag0
print('flag0 =', flag0)     # flag0 = True
print('flag1 =', flag1)     # flag1 = True
print('flag2 =', flag2)     # flag2 = False
print('flag3 =', flag3)     # flag3 = False
print('flag4 =', flag4)     # flag4 = True
print('flag5 =', flag5)     # flag5 = False
print(flag1 and not flag2)  # True
print(1 > 2 or 2 == 3)      # False
```

> **Not**: Karşılaştırma operatörlerinin önceliği atama operatöründen yüksektir; bu nedenle yukarıdaki `flag0 = 1 == 1` ifadesinde önce `1 == 1` işlemi yapılıp `True` değeri üretilir, sonra bu değer `flag0` değişkenine atanır. `print` fonksiyonu birden çok değer yazdırabilir; değerler `,` ile ayrılır ve çıktıda varsayılan olarak boşlukla ayrılır.

### Operatörler ve İfadelerin Uygulaması

#### Örnek 1: Fahrenheit'ı Santigrat'a Çevirme

> **Gereksinim**: Girilen Fahrenheit sıcaklığını Santigrat'a çevir. Fahrenheit'tan Santigrat'a dönüşüm formülü: $\small{C = (F - 32) / 1.8}$.

```python
"""
Fahrenheit sıcaklığını Santigrat'a çevirme

Version: 1.0
Author: 骆昊 (jackfrued)
"""
f = float(input('Fahrenheit sıcaklığını girin: '))
c = (f - 32) / 1.8
print('%.1f Fahrenheit = %.1f Santigrat' % (f, c))
```

> **Not**: Yukarıdaki koddaki `input` fonksiyonu klavyeden kullanıcı girdisi almak için kullanılır; girdiler string olduğundan, sonraki işlemlerde kullanmak için ondalıklı sayıya çevirmek isterseniz, bir önceki derste anlattığımız tür dönüştürme yöntemini kullanıp `float` fonksiyonuyla `str` tipini `float` tipine çevirebilirsiniz.

Yukarıdaki kodda `print` fonksiyonunun çıktısını biçimlendirdik. `print` ile yazdırılan string'de iki adet `%.1f` yer tutucusu (placeholder) vardır; bu iki yer tutucusu, `%`'den sonraki `(f, c)` içindeki iki `float` değişkeninin değeriyle değiştirilir; kayan noktalı sayıda ondalık ayracından sonra 1 basamak tutulur. String'de `%d` yer tutucusu varsa `int` tipinde bir değerle, `%s` yer tutucusu varsa `str` tipinde bir değerle değiştirilir.

Yukarıdaki biçimlendirme yönteminin yanı sıra Python'da aşağıdaki yöntemle de çıktı biçimlendirilebilir. Yer tutucusu içeren bir string veririz; string'in başındaki `f` harfi, bu string'in biçimlendirilmesi gerektiğini belirtir. İçindeki `{f:.1f}` ve `{c:.1f}` önce `{f}` ve `{c}` gibi düşünülebilir; yani çıktı sırasında `f` ve `c` değişkenlerinin değerleri bu yer tutucuların yerine geçer. Arkadaki `:.1f` ise bunun bir kayan noktalı sayı olduğunu ve ondalık ayracından sonra 1 basamak tutulacağını belirtir.

```python
"""
Fahrenheit sıcaklığını Santigrat'a çevirme

Version: 1.1
Author: 骆昊 (jackfrued)
"""
f = float(input('Fahrenheit sıcaklığını girin: '))
c = (f - 32) / 1.8
print(f'{f:.1f} Fahrenheit = {c:.1f} Santigrat')
```

#### Örnek 2: Dairenin Çevresini ve Alanını Hesaplama

> **Gereksinim**: Bir dairenin yarıçapı ($\small{r}$) girilsin; çevresi ($\small{2 \pi r}$) ve alanı ($\small{\pi r^{2}}$) hesaplansın.

```python
"""
Yarıçapı girerek dairenin çevresini ve alanını hesaplama

Version: 1.0
Author: 骆昊 (jackfrued)
"""
radius = float(input('Dairenin yarıçapını girin: '))
perimeter = 2 * 3.1416 * radius
area = 3.1416 * radius * radius
print('Çevre: %.2f' % perimeter)
print('Alan: %.2f' % area)
```

Python'da `math` adında yerleşik bir modül vardır; bu modülde `pi` adında bir değişken tanımlıdır ve değeri pi sayısıdır. Python'un yerleşik `pi` değerini kullanmak isterseniz yukarıdaki kodu biraz değiştirebiliriz.

```python
"""
Yarıçapı girerek dairenin çevresini ve alanını hesaplama

Version: 1.1
Author: 骆昊 (jackfrued)
"""
import math

radius = float(input('Dairenin yarıçapını girin: '))
perimeter = 2 * math.pi * radius
area = math.pi * radius ** 2
print(f'Çevre: {perimeter:.2f}')
print(f'Alan: {area:.2f}')
```

> **Not**: Yukarıdaki koddaki `import math`, `math` modülünü içe aktarmak anlamına gelir; bu modülü içe aktardıktan sonra `math.pi` ile pi sayısının değerine ulaşabiliriz.

Burada aslında bir biçimlendirme yöntemi daha vardır; Python 3.8'de eklenen yeni bir özelliktir. Aşağıdaki koda bakınca anlarsınız.

```python
"""
Yarıçapı girerek dairenin çevresini ve alanını hesaplama

Version: 1.2
Author: 骆昊 (jackfrued)
"""
import math

radius = float(input('Dairenin yarıçapını girin: '))  # Girdi: 5.5
perimeter = 2 * math.pi * radius
area = math.pi * radius ** 2
print(f'{perimeter = :.2f}')  # Çıktı: perimeter = 34.56
print(f'{area = :.2f}')       # Çıktı: area = 95.03
```

> **Not**: Diyelim ki `a` değişkeninin değeri `9.87`; o zaman `f'{a = }'` string'inin değeri `a = 9.87`, `f'{a = :.1f}'` string'inin değeri ise `a = 9.9` olur. Bu biçimlendirme yöntemi hem değişken adını hem de değerini birlikte yazdırır.

#### Örnek 3: Artık Yıl Belirleme

Gereksinim: 1582'den sonraki bir yıl girilsin; bu yılın artık yıl olup olmadığı belirlensin.

```python
"""
Yıl girilsin; artık yılsa True, değilse False çıktısı versin

Version: 1.0
Author: 骆昊 (jackfrued)
"""
year = int(input('Yılı girin: '))
is_leap = year % 4 == 0 and year % 100 != 0 or year % 400 == 0
print(f'{is_leap = }')
```

> **Not**: Gregoryen takvim (bugün kullandığımız miladi takvim) için artık yıl belirleme kuralları şunlardır: 1. 4'ün katı olmayan yıllar normal yıldır; 2. 4'ün katı olup 100'ün katı olmayan yıllar artık yıldır; 3. 400'ün katı olan yıllar artık yıldır. Gregoryen takvim, Papa XIII. Gregorius tarafından Ekim 1582'de, Jülyen takvimin değiştirilmesi ve yerine geçmesi amacıyla tanıtılmıştır; yıl girerken buna dikkat etmeliyiz. Yukarıdaki kod `%` operatörüyle `year` değerinin `4`'ün, `100`'ün ve `400`'ün katı olup olmadığını kontrol eder, sonra `and` ve `or` operatörleriyle üç koşulu bir araya getirir; ilk iki koşul birlikte sağlanmalı, üçüncü koşul ise ilk iki koşulun kombinasyonuyla yalnızca birinin sağlanması yeterlidir.
