### Statik Kaynakları Yükleme

Django projesinde statik kaynak kullanmak istiyorsanız, önce statik kaynakları saklamak için bir dizin oluşturabilirsiniz. `vote` projesinde statik kaynakları `static` adlı klasöre koyduk; bu klasör css, js ve images olmak üzere üç alt klasör içerir; sırasıyla dış CSS dosyalarını, dış JavaScript dosyalarını ve görsel kaynaklarını saklar; aşağıdaki gibidir.

![](res/pycharm-django-static.png)

Statik kaynakları saklayan klasörü bulabilmek için Django projesinin yapılandırma dosyası `settings.py`'yi de değiştirmemiz gerekir; aşağıdaki gibidir:

```Python
STATICFILES_DIRS = [os.path.join(BASE_DIR, 'static'), ]
STATIC_URL = '/static/'
```

Statik kaynakları yapılandırdıktan sonra projeyi çalıştırıp, daha önce yazdığımız sayfadaki görsellerin düzgün yüklenip yüklenmediğine bakabilirsiniz. Belirtmek gerekir ki proje resmen çevrimiçi ortama dağıtıldıktan sonra, statik kaynakları genellikle Python kodu çalıştıran sunucuya değil, özel statik kaynak sunucusuna (Nginx, Apache gibi) devrederiz; bu yüzden yukarıdaki yapılandırma üretim ortamına uygun değildir; yalnızca proje geliştirme aşamasında test içindir. Statik kaynakları kullanmanın doğru yöntemini ileriki bölümlerde anlatacağız.

### Ajax'a Genel Bakış

Şimdi "olumlu oy" ve "olumsuz oy" işlevlerini gerçekleştirebiliriz; açıkça, sayfayı yenilemeden bu iki işlevi gerçekleştirmek daha iyi bir kullanıcı deneyimi sağlar; bu yüzden "olumlu oy" ve "olumsuz oy" işlevleri için [Ajax](https://zh.wikipedia.org/wiki/AJAX) teknolojisini kullanmayı düşünüyoruz. Ajax, Asynchronous Javascript And XML'in kısaltmasıdır; basitçe söylemek gerekirse Ajax teknolojisiyle tüm sayfayı yeniden yüklemeden sayfada yerel yenileme yapılabilir.

Geleneksel Web uygulamalarında, sayfada her yeni içerik yüklenmesi gerektiğinde sunucuya yeniden istek atılıp tüm sayfa yenilenir; sunucu kısa sürede yanıt veremezse veya ağ durumu iyi değilse, tarayıcı uzun süre boş kalıp kullanıcıyı bekletir; bu sürede kullanıcı hiçbir şey yapamaz; aşağıdaki gibidir. Açıkça böyle bir Web uygulaması iyi bir kullanıcı deneyimi sunmaz.

![](res/synchronous-web-request.png)

Ajax teknolojisi kullanan Web uygulamalarında tarayıcı, sunucuya veri almak için asenkron istek atabilir. Asenkron istek kullanıcı deneyimini kesintiye uğratmaz; sunucu yeni veri döndürdüğünde, JavaScript koduyla DOM işlemi yapıp sayfada yerel yenileme gerçekleştirebiliriz; bu, tüm sayfayı yenilemeden sayfanın içeriğini güncellemek gibidir; aşağıdaki gibidir.

![](res/asynchronous-web-request.png)

Ajax teknolojisi kullanılırken tarayıcı ile sunucu genellikle XML veya JSON biçiminde veri alışverişi yapar; XML eskiden çok kullanılan bir veri biçimiydi, son yıllarda neredeyse tamamen JSON ile değiştirildi; aşağıda iki veri biçiminin karşılaştırması vardır.

XML biçimi:

```XML
<?xml version="1.0" encoding="utf-8"?>
<message>
	<from>Alice</from>
    <to>Bob</to>
    <content>Dinner is on me!</content>
</message>
```

JSON biçimi:

```JSON
{
    "from": "Alice",
    "to": "Bob",
    "content": "Dinner is on me!"
}
```

Yukarıdaki karşılaştırmadan, JSON biçimindeki verinin açıkça çok daha kompakt olduğu görülür; bu yüzden aktarım verimliliği daha yüksektir; ayrıca JSON'un kendisi JavaScript'teki bir nesne ifade sözdizimidir; JavaScript kodunda JSON biçimindeki veriyi işlemek daha pratiktir.

### Ajax ile Oylama İşlevini Gerçekleştirme

Aşağıda Ajax teknolojisiyle oylama işlevini gerçekleştiriyoruz; önce projenin `urls.py` dosyasını değiştirip "olumlu oy" ve "olumsuz oy" işlevlerine karşılık gelen URL'leri eşleyin.

```Python
from django.contrib import admin
from django.urls import path

from polls import views

urlpatterns = [
    path('', views.show_subjects),
    path('teachers/', views.show_teachers),
    path('praise/', views.praise_or_criticize),
    path('criticize/', views.praise_or_criticize),
    path('admin/', admin.site.urls),
]
```

"Olumlu oy" ve "olumsuz oy" işlevlerini desteklemek için `praise_or_criticize` görünüm fonksiyonunu tasarlayın; bu fonksiyon, Django'nun kapsüllediği JsonResponse sınıfıyla sözlüğü JSON string'ine serileştirip tarayıcıya dönen yanıt içeriği olarak verir.

```Python
def praise_or_criticize(request):
    """Olumlu oy"""
    try:
        tno = int(request.GET.get('tno'))
        teacher = Teacher.objects.get(no=tno)
        if request.path.startswith('/praise'):
            teacher.good_count += 1
            count = teacher.good_count
        else:
            teacher.bad_count += 1
            count = teacher.bad_count
        teacher.save()
        data = {'code': 20000, 'mesg': 'İşlem başarılı', 'count': count}
    except (ValueError, Teacher.DoseNotExist):
        data = {'code': 20001, 'mesg': 'İşlem başarısız'}
    return JsonResponse(data)
```
