### Excel'e Giriş

Excel, Microsoft'un Windows ve macOS işletim sistemleri için geliştirdiği bir elektronik tablo yazılımıdır. Excel; sezgisel arayüzü, mükemmel hesaplama işlevleri ve grafik araçları ile başarılı pazarlaması sayesinde, uzun süredir en popüler kişisel bilgisayar veri işleme yazılımı olmuştur. Elbette Excel'in Google Sheets, LibreOffice Calc, Numbers gibi birçok rakibi de vardır; bu rakipler temelde Excel ile uyumludur, en azından yeni sürüm Excel dosyalarını okuyup yazabilir; tabii bunlar tartışmamızın odağı değil. Python programıyla Excel dosyası işlemeyi öğrenmek, günlük ofis otomasyonu işlerini daha keyifli hale getirir; ayrıca birçok ticari projede Excel dosyası içe/dışa aktarma özellikle yaygın bir işlevdir.

Bu bölümde, `openpyxl` adlı başka bir üçüncü taraf kütüphaneye dayalı olarak Excel dosyası işleminin nasıl yapılacağını anlatıyoruz; önce onu kurmamız gerekir.

```Bash
pip install openpyxl
```

`openpyxl`'in avantajı, bir Excel dosyasını açtıktan sonra hem okuma hem yazma işlemi yapabilmemizdir; kullanım kolaylığı açısından da `xlwt` ve `xlrd`'den üstündür. Ayrıca stil düzenleme ve formül hesaplama yapmak istiyorsanız, `openpyxl` kullanmak bir önceki bölümde anlattığımız yöntemden çok daha basittir; üstelik `openpyxl` veri özeti ve grafik ekleme gibi işlemleri de destekler; işlevi çok güçlüdür. Bir noktayı tekrar vurgulayalım: `openpyxl`, Office 2007 öncesi sürüm Excel dosyalarını işlemeyi desteklemez.

### Excel Dosyası Okuma

Örneğin mevcut klasörde "alibaba-2020-hisse-verileri.xlsx" adında bir Excel dosyası olsun; bu dosyanın içeriğini okuyup göstermek istiyorsanız aşağıdaki kodu kullanabilirsiniz.

```python
import datetime

import openpyxl

# Bir çalışma kitabı yükle ---> Workbook
wb = openpyxl.load_workbook('alibaba-2020-hisse-verileri.xlsx')
# Çalışma sayfasının adını al
print(wb.sheetnames)
# Çalışma sayfasını al ---> Worksheet
sheet = wb.worksheets[0]
# Hücre aralığını al
print(sheet.dimensions)
# Satır ve sütun sayısını al
print(sheet.max_row, sheet.max_column)

# Belirtilen hücrenin değerini al
print(sheet.cell(3, 3).value)
print(sheet['C3'].value)
print(sheet['G255'].value)

# Birden çok hücre al (iç içe demet)
print(sheet['A2:C5'])

# Tüm hücrelerin verisini oku
for row_ch in range(2, sheet.max_row + 1):
    for col_ch in 'ABCDEFG':
        value = sheet[f'{col_ch}{row_ch}'].value
        if type(value) == datetime.datetime:
            print(value.strftime('%Y yıl %m ay %d gün'), end='\t')
        elif type(value) == int:
            print(f'{value:<10d}', end='\t')
        elif type(value) == float:
            print(f'{value:.4f}', end='\t')
        else:
            print(value, end='\t')
    print()
```

> **İpucu**: Yukarıdaki kodda kullanılan "alibaba-2020-hisse-verileri.xlsx" Excel dosyasını, aşağıdaki Baidu ağ disk adresinden edinebilirsiniz. Bağlantı: https://pan.baidu.com/s/1rQujl5RQn9R7PadB2Z5g_g  çıkarma kodu: e7b4.

Bir noktayı hatırlatalım: `openpyxl` ile belirtilen hücreyi almanın iki yolu vardır. Biri `cell` metodu kullanmaktır; dikkat, bu metodun satır ve sütun indeksleri `1`'den başlar; bu, Excel'e alışık kişilerin alışkanlığını gözetmek içindir. Diğeri ise indeksleme işlemidir; hücrenin koordinatını belirterek, örneğin `C3`, `G255`, karşılık gelen hücreyi alabilir, sonra hücre nesnesinin `value` özniteliğiyle hücrenin değerine ulaşabilirsiniz. Yukarıdaki koddan, `sheet['A2:C5']` veya `sheet['A2':'C5']` gibi dilimleme işlemleriyle birden çok hücrenin alınabildiğini de fark etmişsinizdir; bu işlem iç içe demet döndürür; yani birden çok satır ve sütun elde edilmiş olur.

### Excel Dosyası Yazma

Aşağıda `openpyxl` kullanarak Excel yazma işlemi yapıyoruz.

```python
import random

import openpyxl

# Birinci adım: çalışma kitabı oluştur (Workbook)
wb = openpyxl.Workbook()

# İkinci adım: çalışma sayfası ekle (Worksheet)
sheet = wb.active
sheet.title = 'Dönem Sonu Notları'

titles = ('Ad', 'Türkçe', 'Matematik', 'İngilizce')
for col_index, title in enumerate(titles):
    sheet.cell(1, col_index + 1, title)

names = ('Ali Yılmaz', 'Ayşe Demir', 'Veli Kaya', 'Fatma Şahin', 'Ahmet Çelik')
for row_index, name in enumerate(names):
    sheet.cell(row_index + 2, 1, name)
    for col_index in range(2, 5):
        sheet.cell(row_index + 2, col_index, random.randrange(50, 101))

# Dördüncü adım: çalışma kitabını kaydet
wb.save('sinav-notlari.xlsx')
```

### Stil Ayarlama ve Formül Hesaplama

`openpyxl` ile Excel işlerken hücre stilini ayarlamak istiyorsanız, doğrudan hücre nesnesinin (`Cell` nesnesinin) öznitelikleriyle işlem yapabilirsiniz. Hücre nesnesinin öznitelikleri; yazı tipi (`font`), hizalama (`alignment`), kenarlık (`border`) vb. içerir; ayrıntılar için `openpyxl`'in [resmî dokümanına](https://openpyxl.readthedocs.io/en/stable/index.html) bakabilirsiniz. `openpyxl` kullanırken formül hesaplama yapmanız gerekirse, tamamen Excel'deki işlem biçimini izleyebilirsiniz; kod aşağıdaki gibidir.

```python
import openpyxl
from openpyxl.styles import Font, Alignment, Border, Side

# Hizalama
alignment = Alignment(horizontal='center', vertical='center')
# Kenarlık çizgisi
side = Side(color='ff7f50', style='mediumDashed')

wb = openpyxl.load_workbook('sinav-notlari.xlsx')
sheet = wb.worksheets[0]

# Satır yüksekliğini ve sütun genişliğini ayarla
sheet.row_dimensions[1].height = 30
sheet.column_dimensions['E'].width = 120

sheet['E1'] = 'Ortalama'
# Yazı tipini ayarla
sheet.cell(1, 5).font = Font(size=18, bold=True, color='ff1493', name='Arial')
# Hizalamayı ayarla
sheet.cell(1, 5).alignment = alignment
# Hücre kenarlığını ayarla
sheet.cell(1, 5).border = Border(left=side, top=side, right=side, bottom=side)
for i in range(2, 7):
    # Formülle her öğrencinin ortalamasını hesapla
    sheet[f'E{i}'] = f'=average(B{i}:D{i})'
    sheet.cell(i, 5).font = Font(size=12, color='4169e1', italic=True)
    sheet.cell(i, 5).alignment = alignment

wb.save('sinav-notlari.xlsx')
```

### İstatistik Grafiği Oluşturma

`openpyxl` kütüphanesiyle doğrudan Excel'e istatistik grafiği ekleyebiliriz; somut yöntem, Excel'de grafik eklemeyle büyük ölçüde aynıdır. Belirtilen tipte bir grafik nesnesi oluşturup, sonra bu nesnenin öznitelikleriyle grafiği ayarlayabiliriz. Elbette en önemlisi, grafiğe veri bağlamaktır; yani yatay eksen neyi, dikey eksen neyi temsil ediyor, somut değerler nedir. Son olarak grafik nesnesi forma eklenebilir; kod aşağıdaki gibidir.

```python
from openpyxl import Workbook
from openpyxl.chart import BarChart, Reference

wb = Workbook(write_only=True)
sheet = wb.create_sheet()

rows = [
    ('Kategori', 'Satış A Grubu', 'Satış B Grubu'),
    ('Telefon', 40, 30),
    ('Tablet', 50, 60),
    ('Dizüstü', 80, 70),
    ('Çevre birimi', 20, 10),
]

# Forma satır ekle
for row in rows:
    sheet.append(row)

# Grafik nesnesi oluştur
chart = BarChart()
chart.type = 'col'
chart.style = 10
# Grafiğin başlığını ayarla
chart.title = 'Satış İstatistik Grafiği'
# Grafiğin dikey eksen başlığını ayarla
chart.y_axis.title = 'Satış adedi'
# Grafiğin yatay eksen başlığını ayarla
chart.x_axis.title = 'Ürün kategorisi'
# Verinin aralığını ayarla
data = Reference(sheet, min_col=2, min_row=1, max_row=5, max_col=3)
# Kategorinin aralığını ayarla
cats = Reference(sheet, min_col=1, min_row=2, max_row=5)
# Grafiğe veri ekle
chart.add_data(data, titles_from_data=True)
# Grafiğe kategori ata
chart.set_categories(cats)
chart.shape = 4
# Grafiği formda belirtilen hücreye ekle
sheet.add_chart(chart, 'A10')

wb.save('demo.xlsx')
```
