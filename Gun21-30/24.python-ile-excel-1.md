### Excel'e Giriş

Excel, Microsoft'un Windows ve macOS işletim sistemleri için geliştirdiği bir elektronik tablo yazılımıdır. Excel; sezgisel arayüzü, mükemmel hesaplama işlevleri ve grafik araçları ile başarılı pazarlaması sayesinde, uzun süredir en popüler kişisel bilgisayar veri işleme yazılımı olmuştur. Elbette Excel'in Google Sheets, LibreOffice Calc, Numbers gibi birçok rakibi de vardır; bu rakipler temelde Excel ile uyumludur, en azından yeni sürüm Excel dosyalarını okuyup yazabilir; tabii bunlar tartışmamızın odağı değil. Python programıyla Excel dosyası işlemeyi öğrenmek, günlük ofis otomasyonu işlerini daha keyifli hale getirir; ayrıca birçok ticari projede Excel dosyası içe/dışa aktarma özellikle yaygın bir işlevdir.

Python'da Excel işlemi, üçüncü taraf kütüphane desteği gerektirir. Excel 2007 öncesi sürümlerle, yani `xls` biçimindeki Excel dosyalarıyla uyumlu olmak istiyorsanız `xlrd` ve `xlwt` üçüncü taraf kütüphanelerini kullanabilirsiniz; birincisi Excel dosyası okumak, ikincisi yazmak içindir. Daha yeni sürüm Excel, yani `xlsx` biçimindeki Excel dosyaları için `openpyxl` kütüphanesi kullanılabilir; elbette bu kütüphane yalnızca Excel'i değil, Office Open XML tabanlı diğer elektronik tablo dosyalarını da işleyebilir.

Bu bölümde önce `xlwt` ve `xlrd` ile Excel dosyası işlemeyi anlatıyoruz; önce aşağıdaki komutla bu iki üçüncü taraf kütüphaneyi ve birlikte kullanılan yardımcı araç modülü `xlutils`'i kurabilirsiniz.


### Excel Dosyası Okuma

Örneğin mevcut klasörde "alibaba-2020-hisse-verileri.xls" adında bir Excel dosyası olsun; bu dosyanın içeriğini okuyup göstermek istiyorsanız aşağıdaki kodu kullanabilirsiniz.

```python
import xlrd

# xlrd modülünün open_workbook fonksiyonuyla belirtilen Excel dosyasını aç ve Book nesnesi (çalışma kitabı) al
wb = xlrd.open_workbook('alibaba-2020-hisse-verileri.xls')
# Book nesnesinin sheet_names metoduyla tüm sayfa adlarını al
sheetnames = wb.sheet_names()
print(sheetnames)
# Belirtilen sayfa adıyla Sheet nesnesini (çalışma sayfası) al
sheet = wb.sheet_by_name(sheetnames[0])
# Sheet nesnesinin nrows ve ncols öznitelikleriyle sayfanın satır ve sütun sayısını al
print(sheet.nrows, sheet.ncols)
for row in range(sheet.nrows):
    for col in range(sheet.ncols):
        # Sheet nesnesinin cell metoduyla belirtilen Cell nesnesini (hücre) al
        # Cell nesnesinin value özniteliğiyle hücredeki değeri al
        value = sheet.cell(row, col).value
        # İlk satır dışındaki satırlarda veri biçimlendirmesi yap
        if row > 0:
            # 1. sütundaki xldate tipini önce demete çevir, sonra "yıl ay gün" biçiminde formatla
            if col == 0:
                # xldate_as_tuple fonksiyonunun ikinci parametresi yalnızca 0 ve 1 değerini alır
                # 0, 1900-01-01'i; 1 ise 1904-01-01'i temel alan tarihi ifade eder
                value = xlrd.xldate_as_tuple(value, 0)
                value = f'{value[0]} yıl {value[1]:>02d} ay {value[2]:>02d} gün'
            # Diğer sütunlardaki number tipini, ondalıktan sonra iki basamak tutan ondalıklı sayıya çevir
            else:
                value = f'{value:.2f}'
        print(value, end='\t')
    print()
# Son hücrenin veri tipini al
# 0 - boş, 1 - string, 2 - sayı, 3 - tarih, 4 - mantıksal, 5 - hata
last_cell_type = sheet.cell_type(sheet.nrows - 1, sheet.ncols - 1)
print(last_cell_type)
# İlk satırın değerini al (liste)
print(sheet.row_values(0))
# Belirtilen satırın belirtilen sütun aralığındaki verisini al (liste)
# İlk parametre satır indeksini, ikinci ve üçüncü parametreler sütunun başlangıç (dahil) ve bitiş (hariç) indekslerini ifade eder
print(sheet.row_slice(3, 0, 5))
```

> **İpucu**: Yukarıdaki kodda kullanılan "alibaba-2020-hisse-verileri.xls" Excel dosyasını, aşağıdaki Baidu ağ disk adresinden edinebilirsiniz. Bağlantı: https://pan.baidu.com/s/1rQujl5RQn9R7PadB2Z5g_g  çıkarma kodu: e7b4.

Yukarıdaki kodla bir Excel dosyasının nasıl okunacağını anladığınıza inanıyorum; `xlrd` modülü hakkında daha fazla bilgi için [resmî dokümanı](https://xlrd.readthedocs.io/en/latest/) okuyabilirsiniz.

### Excel Dosyası Yazma

Excel dosyasına yazmak için `xlwt` modülünün `Workbook` sınıfıyla çalışma kitabı nesnesi oluşturulabilir; çalışma kitabı nesnesinin `add_sheet` metoduyla çalışma sayfası eklenebilir; çalışma sayfası nesnesinin `write` metoduyla belirtilen hücreye veri yazılabilir; son olarak çalışma kitabı nesnesinin `save` metoduyla çalışma kitabı belirtilen dosyaya veya belleğe yazılır. Aşağıdaki kod, 5 öğrencinin 3 dersinin sınav notlarını Excel dosyasına yazar.

```python
import random

import xlwt

student_names = ['Ali Yılmaz', 'Ayşe Demir', 'Veli Kaya', 'Fatma Şahin', 'Ahmet Çelik']
scores = [[random.randrange(50, 101) for _ in range(3)] for _ in range(5)]
# Çalışma kitabı nesnesi oluştur (Workbook)
wb = xlwt.Workbook()
# Çalışma sayfası nesnesi oluştur (Worksheet)
sheet = wb.add_sheet('1-A Sınıfı')
# Başlık verisini ekle
titles = ('Ad', 'Türkçe', 'Matematik', 'İngilizce')
for index, title in enumerate(titles):
    sheet.write(0, index, title)
# Öğrenci adlarını ve sınav notlarını hücrelere yaz
for row in range(len(scores)):
    sheet.write(row + 1, 0, student_names[row])
    for col in range(len(scores[row])):
        sheet.write(row + 1, col + 1, scores[row][col])
# Excel çalışma kitabını kaydet
wb.save('sinav-notlari.xls')
```

### Hücre Stilini Ayarlama

Excel dosyasına yazarken hücrelere stil de ayarlayabiliriz; esas olarak yazı tipi (Font), hizalama (Alignment), kenarlık (Border) ve arka plan (Background) ayarları yapılır; `xlwt` bu ayarların her biri için ilgili sınıfları kapsülleyerek destekler. Hücre stili ayarlamak için önce bir `XFStyle` nesnesi oluşturmak, sonra bu nesnenin öznitelikleriyle yazı tipini, hizalamayı, kenarlığı vb. ayarlamak gerekir. Örneğin yukarıdaki örnekte başlık hücrelerinin arka plan rengini sarıya çevirmek istiyorsak şu şekilde işlem yapabiliriz.

```python
header_style = xlwt.XFStyle()
pattern = xlwt.Pattern()
pattern.pattern = xlwt.Pattern.SOLID_PATTERN
# 0 - siyah, 1 - beyaz, 2 - kırmızı, 3 - yeşil, 4 - mavi, 5 - sarı, 6 - pembe, 7 - camgöbeği
pattern.pattern_fore_colour = 5
header_style.pattern = pattern
titles = ('Ad', 'Türkçe', 'Matematik', 'İngilizce')
for index, title in enumerate(titles):
    sheet.write(0, index, title, header_style)
```

Başlık için belirli bir yazı tipi ayarlamak istiyorsanız `Font` sınıfını kullanıp aşağıdaki kodu ekleyebilirsiniz.

```python
font = xlwt.Font()
# Yazı tipi adı
font.name = 'Arial'
# Yazı tipi boyutu (20 temel birimdir, 18, 18px demektir)
font.height = 20 * 18
# Kalın kullanılsın mı
font.bold = True
# İtalik kullanılsın mı
font.italic = False
# Yazı tipi rengi
font.colour_index = 1
header_style.font = font
```

> **Dikkat**: Yukarıdaki kodda belirtilen yazı tipi adı (`font.name`), yerel sistemde bulunan bir yazı tipi olmalıdır; örneğin benim bilgisayarımda "Arial" adlı bir yazı tipi vardır.

Başlığın dikey olarak ortalanmasını istiyorsanız aşağıdaki kodu kullanabilirsiniz.

```python
align = xlwt.Alignment()
# Dikey hizalama
align.vert = xlwt.Alignment.VERT_CENTER
# Yatay hizalama
align.horz = xlwt.Alignment.HORZ_CENTER
header_style.alignment = align
```

Başlığa sarı kesikli kenarlık eklemek istiyorsanız aşağıdaki kodu kullanabilirsiniz.

```python
borders = xlwt.Borders()
props = (
    ('top', 'top_colour'), ('right', 'right_colour'),
    ('bottom', 'bottom_colour'), ('left', 'left_colour')
)
# Döngüyle dört yönün kenarlık stilini ve rengini ayarla
for position, color in props:
    # setattr yerleşik fonksiyonuyla nesnenin belirtilen özniteliğine dinamik değer ata
    setattr(borders, position, xlwt.Borders.DASHED)
    setattr(borders, color, 5)
header_style.borders = borders
```

Hücrenin genişliğini (sütun genişliği) ve başlığın yüksekliğini (satır yüksekliği) ayarlamak istiyorsanız aşağıdaki kodu kullanabilirsiniz.

```python
# Satır yüksekliğini 40px yap
sheet.row(0).set_style(xlwt.easyxf(f'font:height {20 * 40}'))
titles = ('Ad', 'Türkçe', 'Matematik', 'İngilizce')
for index, title in enumerate(titles):
    # Sütun genişliğini 200px yap
    sheet.col(index).width = 20 * 200
    # Hücrenin verisini ve stilini yaz
    sheet.write(0, index, title, header_style)
```

### Formül Hesaplama

Daha önce açtığımız "alibaba-2020-hisse-verileri.xls" dosyası için, yıl boyu kapanış fiyatının (Close alanı) ortalamasını ve yıl boyu işlem hacminin (Volume alanı) toplamını hesaplamak istiyorsak Excel'in formül hesaplamasını kullanabiliriz. Önce `xlrd` ile Excel dosyasını okuyup, sonra `xlutils` üçüncü taraf kütüphanesinin sunduğu `copy` fonksiyonuyla okunan Excel dosyasını yazma işlemi için `Workbook` nesnesine dönüştürebiliriz; `write` metodunu çağırırken hücreye bir `Formula` nesnesi yazılabilir.

Formül hesaplamasını gerçekleştiren kod aşağıdaki gibidir.

```python
import xlrd
import xlwt
from xlutils.copy import copy

wb_for_read = xlrd.open_workbook('alibaba-2020-hisse-verileri.xls')
sheet1 = wb_for_read.sheet_by_index(0)
nrows, ncols = sheet1.nrows, sheet1.ncols
wb_for_write = copy(wb_for_read)
sheet2 = wb_for_write.get_sheet(0)
sheet2.write(nrows, 4, xlwt.Formula(f'average(E2:E{nrows})'))
sheet2.write(nrows, 6, xlwt.Formula(f'sum(G2:G{nrows})'))
wb_for_write.save('alibaba-2020-hisse-verileri-ozet.xls')
```

> **Not**: Yukarıdaki kodda bazı küçük kusurlar vardır; merak edenler kendileri keşfedip nasıl çözüleceğini düşünebilir.

###  Özet

Python programıyla Excel işleme yöntemini öğrenmek, günlük ofis işlerindeki birçok zahmetli Excel elektronik tablo işini çözebilir; en yaygın olanları, aynı veri biçimindeki birden çok Excel dosyasını tek dosyada birleştirmek ve birden çok Excel dosyasından veya sayfasından belirtilen veriyi çıkarmaktır. Elbette tablo verisini işlemek istiyorsanız, Python veri analizi harikalarından biri olan pandas kütüphanesini kullanmak daha da pratik olabilir.
