## Python ile PDF Dosyaları

> **Translated to Turkish by** himmetcanumutlu

PDF, "Portable Document Format"ın kısaltmasıdır; bu tür dosyalar genellikle `.pdf` uzantısını kullanır. Günlük geliştirme işlerinde en sık karşılaşılan iki görev, PDF'ten metin okumak ve mevcut içerikle PDF belgesi üretmektir.

### PDF'ten Metin Çıkarma

Python'da PDF dosyası okumak için `PyPDF2` adlı üçüncü taraf kütüphane kullanılabilir; kurmak için aşağıdaki komutu kullanabilirsiniz.

```Bash
pip install PyPDF2
```

`PyPDF2`, PDF belgesinden görsel, grafik veya diğer ortamları çıkaramaz; ancak metni çıkarıp Python string'i olarak döndürebilir.

```python
import PyPDF2

reader = PyPDF2.PdfReader('test.pdf')
for page in reader.pages:
    print(page.extract_text())
```

Elbette `PyPDF2` her PDF belgesinden metin çıkaramaz; bildiğim kadarıyla bu sorunun özellikle iyi bir çözümü yok; özellikle Çince çıkarırken. İnternette PDF'ten metin çıkarmayı anlatan birçok yazı var; [《Üç Harika Araçla Python PDF Belge Bilgisi Çıkarma》](https://cloud.tencent.com/developer/article/1395339) yazısını okuyup bilgi edinmenizi öneririz.

PDF dosyasından metin çıkarmak için doğrudan üçüncü taraf komut satırı araçları da kullanılabilir; somut yöntem aşağıdaki gibidir.

```Bash
pip install pdfminer.six
pdf2text.py test.pdf
```

### Sayfa Döndürme ve Üst Üste Bindirme

Yukarıdaki kodda `PdfReader` nesnesi oluşturarak PDF belgesini okuduk; bu nesnenin `pages` özelliği üzerinden gezinerek belgenin sayfalarını alabiliriz; `PageObject` nesnesinin `rotate` metoduyla sayfa döndürülebilir; `addBlankPage` gibi işlemler de yapılabilir; kod aşağıdaki gibidir.

```python
reader = PyPDF2.PdfReader('XGBoost.pdf')
writer = PyPDF2.PdfWriter()

for no, page in enumerate(reader.pages):
    if no % 2 == 0:
        new_page = page.rotate(-90)
    else:
        new_page = page.rotate(90)
    writer.add_page(new_page)

with open('temp.pdf', 'wb') as file_obj:
    writer.write(file_obj)
```

### PDF Dosyasını Şifreleme

`PyPDF2`'deki `PdfWriter` nesnesiyle PDF belgesi şifrelenebilir; bir dizi PDF belgesine tek tip erişim parolası ayarlamak gerekiyorsa, Python programıyla işlemek çok pratiktir.

```python
import PyPDF2

reader = PyPDF2.PdfReader('XGBoost.pdf')
writer = PyPDF2.PdfWriter()

for page in reader.pages:
    writer.add_page(page)
    
writer.encrypt('foobared')

with open('temp.pdf', 'wb') as file_obj:
    writer.write(file_obj)
```

### Toplu Filigran Ekleme

Yukarıda sözü edilen `PageObject` nesnesinin `merge_page` adında bir metodu daha vardır; iki PDF sayfasını üst üste bindirebilir; bu işlemle PDF dosyasına filigran ekleme işlevini kolayca gerçekleştirebiliriz. Örneğin yukarıdaki "XGBoost.pdf" dosyasına filigran eklemek istiyorsak, önce filigran sayfası sağlayan bir PDF dosyası hazırlayıp, filigranı içeren `PageObject`'i okuyup, sonra "XGBoost.pdf" dosyasının her sayfasını döngüyle gezip `PageObject` nesnesini alıp `merge_page` metoduyla filigran sayfası ile asıl sayfayı birleştirebiliriz; kod aşağıdaki gibidir.

```python
reader1 = PyPDF2.PdfReader('XGBoost.pdf')
reader2 = PyPDF2.PdfReader('watermark.pdf')
writer = PyPDF2.PdfWriter()
watermark_page = reader2.pages[0]

for page in reader1.pages:
    page.merge_page(watermark_page)
    writer.add_page(page)

with open('temp.pdf', 'wb') as file_obj:
    writer.write(file_obj)
```

İsterseniz tek ve çift sayfaların farklı filigranlar kullanmasını da sağlayabilirsiniz; nasıl yapılacağını kendiniz düşünebilirsiniz.

### PDF Dosyası Oluşturma

PDF belgesi oluşturmak, üçüncü taraf `reportlab` kütüphanesinin desteğini gerektirir; kurulum yöntemi aşağıdaki gibidir.

```Bash
pip install reportlab
```

Aşağıda bir örnekle `reportlab`'ın kullanımını gösterelim.

```python
from reportlab.lib.pagesizes import A4
from reportlab.pdfbase import pdfmetrics
from reportlab.pdfbase.ttfonts import TTFont
from reportlab.pdfgen import canvas

pdf_canvas = canvas.Canvas('resources/demo.pdf', pagesize=A4)
width, height = A4

# Çizim
image = canvas.ImageReader('resources/guido.jpg')
pdf_canvas.drawImage(image, 20, height - 395, 250, 375)

# Mevcut sayfayı göster
pdf_canvas.showPage()

# Yazı tipi dosyasını kaydet
pdfmetrics.registerFont(TTFont('Font1', 'resources/fonts/Vera.ttf'))
pdfmetrics.registerFont(TTFont('Font2', 'resources/fonts/qinggua.ttf'))

# Yazı yaz
pdf_canvas.setFont('Font2', 40)
pdf_canvas.setFillColorRGB(0.9, 0.5, 0.3, 1)
pdf_canvas.drawString(width // 2 - 120, height // 2, 'Merhaba, dünya!')
pdf_canvas.setFont('Font1', 40)
pdf_canvas.setFillColorRGB(0, 1, 0, 0.5)
pdf_canvas.rotate(18)
pdf_canvas.drawString(250, 250, 'hello, world!')

# Kaydet
pdf_canvas.save()
```

Yukarıdaki kodu anlamadıysanız sorun değil; gerçekten Python ile PDF belgesi oluşturmanız gerektiğinde `reportlab`'ın [resmî dokümanını](https://www.reportlab.com/docs/reportlab-userguide.pdf) dikkatle incelemeniz yeterlidir.
