## Eş Zamanlı Programlamanın Tarayıcıda Uygulanması

> **Translated to Turkish by** himmetcanumutlu

Önceki derslerde Python'daki çoklu iş parçacığı, çoklu işlem ve asenkron programlamayı tanıttık; bu üç yolla eş zamanlı veya paralel programlama yapılabilir; bu hem kodun çalışmasını hızlandırır hem de daha iyi kullanıcı deneyimi sağlar. Tarayıcı programı tipik bir I/O yoğun görevdir; I/O yoğun görevler için çoklu iş parçacığı ve asenkron I/O iyi seçimlerdir; çünkü programın bir kısmı I/O işlemiyle bloklandığında diğer kısımları çalışmaya devam eder; böylece bekleme ve bloklanmada çok zaman harcamayız. Aşağıda "[360 görsel](https://image.so.com/)" sitesinden görsel çekip yerel diske kaydetme örneğiyle, tek iş parçacıklı, çoklu iş parçacıklı ve asenkron I/O'lu tarayıcı programlarının farkını gösteriyor, aynı zamanda çalışma verimliliklerini basitçe karşılaştırıyoruz.

"360 görsel" sitesinin sayfası [Ajax](https://developer.mozilla.org/zh-CN/docs/Web/Guide/AJAX) teknolojisi kullanır; bu, birçok sitenin kullandığı, veriyi asenkron yükleyip sayfayı yerel yenileyen bir teknolojidir. Basitçe söylemek gerekirse sayfadaki görseller JavaScript koduyla asenkron JSON verisi alınıp dinamik render edilir; ayrıca sayfa şelale biçiminde yüklenir (aşağı kaydırdıkça daha fazla görsel yüklenir). Tarayıcının "Geliştirici araçları"nda dinamik içeriği sağlayan veri arayüzünü bulabiliriz; aşağıdaki gibidir; ihtiyacımız olan görsel bilgisi sunucunun döndürdüğü JSON verisindedir.

Örneğin "güzellik" kanalının görsellerini almak için aşağıdaki URL'e istek atabiliriz; `ch` parametresi istenen kanalı belirtir; `=`'den sonraki `beauty` değeri "güzellik" kanalını temsil eder; `sn` parametresi sayfa numarası gibidir; `0` ilk sayfayı (toplam `30` görsel), `30` ikinci sayfayı, `60` üçüncü sayfayı temsil eder; böyle devam eder.

```
https://image.so.com/zjl?ch=beauty&sn=0
```

### Tek İş Parçacıklı Sürüm

Yukarıdaki URL ile "güzellik" kanalından toplam `90` görsel indirelim.

```Python
"""
example04.py - Tek iş parçacıklı sürüm tarayıcı
"""
import os

import requests


def download_picture(url):
    filename = url[url.rfind('/') + 1:]
    resp = requests.get(url)
    if resp.status_code == 200:
        with open(f'images/beauty/{filename}', 'wb') as file:
            file.write(resp.content)


def main():
    if not os.path.exists('images/beauty'):
        os.makedirs('images/beauty')
    for page in range(3):
        resp = requests.get(f'https://image.so.com/zjl?ch=beauty&sn={page * 30}')
        if resp.status_code == 200:
            pic_dict_list = resp.json()['list']
            for pic_dict in pic_dict_list:
                download_picture(pic_dict['qhimg_url'])

if __name__ == '__main__':
    main()
```

macOS veya Linux'ta `time` komutuyla yukarıdaki kodun çalışma süresini ve CPU kullanımını görebiliriz; aşağıdaki gibidir.

```Bash
time python3 example04.py 
```

Aşağıda tek iş parçacıklı tarayıcı kodunun bilgisayarımda çalışma sonucu vardır.

```
python3 example04.py  2.36s user 0.39s system 12% cpu 21.578 total
```

Burada yalnızca kodun toplam süresinin `21.578` saniye, CPU kullanımının `%12` olduğuna odaklanmamız gerekiyor.

### Çoklu İş Parçacıklı Sürüm

Daha önce anlattığımız iş parçacığı havuzu tekniğini kullanıp yukarıdaki kodu çoklu iş parçacıklı sürüme değiştirelim.

```Python
"""
example05.py - Çoklu iş parçacıklı sürüm tarayıcı
"""
import os
from concurrent.futures import ThreadPoolExecutor

import requests


def download_picture(url):
    filename = url[url.rfind('/') + 1:]
    resp = requests.get(url)
    if resp.status_code == 200:
        with open(f'images/beauty/{filename}', 'wb') as file:
            file.write(resp.content)


def main():
    if not os.path.exists('images/beauty'):
        os.makedirs('images/beauty')
    with ThreadPoolExecutor(max_workers=16) as pool:
        for page in range(3):
            resp = requests.get(f'https://image.so.com/zjl?ch=beauty&sn={page * 30}')
            if resp.status_code == 200:
                pic_dict_list = resp.json()['list']
                for pic_dict in pic_dict_list:
                    pool.submit(download_picture, pic_dict['qhimg_url'])


if __name__ == '__main__':
    main()
```

Aşağıdaki komutu çalıştırın.

```Bash
time python3 example05.py
```

Kodun çalışma sonucu aşağıdaki gibidir:

```
python3 example05.py  2.65s user 0.40s system 95% cpu 3.193 total
```

### Asenkron I/O Sürümü

`aiohttp` ile yukarıdaki kodu asenkron I/O sürümüne değiştirelim. Ağ kaynağı almayı ve dosya yazmayı asenkron I/O ile yapmak için önce `aiohttp` ve `aiofile` üçüncü taraf kütüphanelerini kurmamız gerekir; komut aşağıdaki gibidir.

```Bash
pip install aiohttp aiofile
```

`aiohttp` kullanımı önceki derste kısaca tanıtıldı; `aiofile` modülündeki `async_open` fonksiyonu Python yerleşik `open` fonksiyonuyla yaklaşık aynı kullanımdadır; yalnızca asenkron işlemi destekler. Aşağıda asenkron I/O sürümü tarayıcı kodu vardır.

```Python
"""
example06.py - Asenkron I/O sürümü tarayıcı
"""
import asyncio
import json
import os

import aiofile
import aiohttp


async def download_picture(session, url):
    filename = url[url.rfind('/') + 1:]
    async with session.get(url, ssl=False) as resp:
        if resp.status == 200:
            data = await resp.read()
            async with aiofile.async_open(f'images/beauty/{filename}', 'wb') as file:
                await file.write(data)


async def fetch_json():
    async with aiohttp.ClientSession() as session:
        for page in range(3):
            async with session.get(
                url=f'https://image.so.com/zjl?ch=beauty&sn={page * 30}',
                ssl=False
            ) as resp:
                if resp.status == 200:
                    json_str = await resp.text()
                    result = json.loads(json_str)
                    for pic_dict in result['list']:
                        await download_picture(session, pic_dict['qhimg_url'])


def main():
    if not os.path.exists('images/beauty'):
        os.makedirs('images/beauty')
    loop = asyncio.get_event_loop()
    loop.run_until_complete(fetch_json())
    loop.close()


if __name__ == '__main__':
    main()
```

Aşağıdaki komutu çalıştırın.

```Bash
time python3 example06.py
```

Kodun çalışma sonucu aşağıdaki gibidir:

```
python3 example06.py  0.82s user 0.21s system 27% cpu 3.782 total
```

### Özet

Yukarıdaki üç kodun çalışma sonuçlarını karşılaştırarak bir sonuca varabiliriz: çoklu iş parçacığı ve asenkron I/O, tarayıcı programının performansını iyileştirir; çünkü I/O işleminin yol açtığı bekleme ve bloklanmada zaman harcamayız; `time` komutunun sonucu da tek iş parçacıklı kodun CPU kullanımının yalnızca `%12`, çoklu iş parçacıklı sürümün CPU kullanımının ise `%95`'e kadar çıktığını gösterir; tek iş parçacıklı tarayıcının çalışma süresi yaklaşık `21` saniye, çoklu iş parçacıklı ve asenkron I/O sürümleri ise yalnızca `3` saniye çalışır. Ayrıca çalışma süresi farkı büyük olmadığında, çoklu iş parçacığı kodu asenkron I/O koduna göre daha fazla CPU kaynağı harcar; çünkü çoklu iş parçacığının çizelgeleme ve geçişi de CPU zamanı harcar. Böylece üç yöntemin I/O yoğun görevlerdeki üstünlüğü netleşti; elbette bu yalnızca benim bilgisayarımdaki sonuç. Ağ durumu iyi değilse veya hedef site yavaş yanıt veriyorsa, çoklu iş parçacığı ve asenkron I/O'nun avantajı daha belirgin olur; merak edenler kendileri deneyebilir.
