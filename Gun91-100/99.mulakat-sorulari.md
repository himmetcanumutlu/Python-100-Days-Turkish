## Mülakatlarda Sık Karşılaşılan Sorular

> **Translated to Turkish by** himmetcanumutlu

### Bilgisayar Temelleri

1. TCP/IP modeliyle ilgili sorular.

   > Ruan Yifeng'in [《İnternet Protokolüne Giriş (1)》](http://www.ruanyifeng.com/blog/2012/05/internet_protocol_suite_part_i.html) ve [《İnternet Protokolüne Giriş (2)》](http://www.ruanyifeng.com/blog/2012/06/internet_protocol_suite_part_ii.html) yazılarını okumanız önerilir.

2. HTTP ve HTTPS ile ilgili sorular.

   > Ruan Yifeng'in [《HTTP Protokolüne Giriş》](http://www.ruanyifeng.com/blog/2016/08/http.html) ve [《SSL/TLS Protokolünün Çalışma Mekanizmasına Genel Bakış》](http://www.ruanyifeng.com/blog/2014/02/ssl_tls.html) yazılarını okumanız önerilir.

3. Yaygın Linux komutları ve servisleri.

4. Süreç (process) ile iş parçacığı (thread) arasındaki ilişki. Ne zaman çok iş parçacıklı, ne zaman çok süreçli kullanılır?

5. İlişkisel veritabanıyla ilgili sorular (ACID, işlem yalıtım seviyesi, kilit, SQL optimizasyonu).

6. İlişkisel olmayan veritabanıyla ilgili sorular (CAP/BASE, uygulama senaryoları).

### Python Temelleri

1. Geliştirmede hangi standart kütüphane ve üçüncü taraf kütüphaneleri kullandınız.

   > Standart kütüphane: sys / os / re / math / random / logging / json / pickle / shelve / socket / datetime / hashlib / configparser / urllib / itertools / collections / functools / threading / multiprocess / timeit / atexit / abc / asyncio / base64 / concurrent.futures / copy / csv / operator / enum / heapq / http / profile / pstats / ssl / unittest / uuid
   >
   > Üçüncü taraf kütüphane: openpyxl / xlrd / xlwt / PyPDF2 / ReportLab / PyYAML / jieba / pillow / requests / urllib3 / responses / aiohttp / BeautifulSoup4 / lxml / pyquery / PyMySQL / psycopg2 / redis / PyMongo / Peewee / SQLAlchemy / alipay / PyJWT / itsdangerous / celery / flower / elasticsearch-dsl-py / PyCrypto / Paramiko / logbook / nose / pytest / coverage / Selenium / lineprofiler / memoryprofiler / matplotlib / pygal / OpenCV

2. Dekoratörün işlevi, prensibi ve uygulanması.

3. Hangi sihirli yöntemleri kullandınız.

   > [《Python Sihirli Yöntemler Kılavuzu》](https://pycoders-weekly-chinese.readthedocs.io/en/latest/issue6/a-guide-to-pythons-magic-methods.html) yazısını okumanız önerilir.

4. Üreteç ifadesi, üreteç ve yineleyicinin yazılması.

5. Liste, küme ve sözlüğün alt katman uygulaması.

6. Çöp toplamayla ilgili sorular.

7. Eş zamanlı programlamayla ilgili sorular.

8. Eş yordam (coroutine) ve asenkron I/O ile ilgili bilgiler.

### Django ve Flask

1. MVC mimarisi (MTV) hangi sorunu çözer.

2. Middleware'in çalışma akışı ve özel middleware nasıl yazılır.

3. REST veri arayüzü nasıl tasarlanır (URL, alan adı, sürüm, filtre, durum kodu, güvenlik).

   > Ruan Yifeng'in [《RESTful API Tasarım Rehberi》](http://www.ruanyifeng.com/blog/2014/05/restful_api.html) yazısını okumanız önerilir.

4. ORM çerçevesiyle CRUD işlemini gerçekleştirmeyle ilgili sorular.

   - Çok koşullu kombinasyon sorgusu nasıl gerçekleştirilir / ham SQL nasıl çalıştırılır / N+1 sorgu problemi nasıl önlenir

5. Asenkron görev ve zamanlanmış görev nasıl çalıştırılır.

6. Sayfa önbelleği ve sorgu önbelleği nasıl gerçekleştirilir? Önbellek nasıl ısıtılır?

### Scraping ile İlgili

1. Scrapy çerçevesinin bileşenleri ve veri işleme akışı.
2. Kazımanın amacı (projede hangi yerlerde scraping verisine ihtiyaç duyulur).
3. Kullanılan araçlar (paket yakalama, indirme, temizleme, depolama, analiz, görselleştirme).
4. Verinin kaynağı (kolayca 10 site sayabilmek).
5. Verinin yapısı (kazınan bir alanın projede ne işe yaradığı).
6. Anti-anti-scraping önlemleri (hız sınırlama, istek başlığı, Cookie havuzu, proxy havuzu, Selenium WebDriver, RoboBrowser, TOR, OCR).
7. Verinin hacmi (sonunda ne kadar veri kazındı, kaç on bin kayıt veya kaç GB veri).
8. Sonraki veri işleme (kalıcılaştırma, veri tamamlama, normalizasyon, biçimlendirme, aktarma, sınıflandırma).

### Veri Analizi

1. Bilimsel hesaplama fonksiyon kütüphaneleri (SciPy ve NumPy yaygın işlemleri).
2. Veri analizi kütüphaneleri (Pandas'ta sarmalanan yaygın algoritmalar).
3. Yaygın modeller ve karşılık gelen senaryolar (sınıflandırma, regresyon, kümeleme).
4. Hangi somut göstergeler çıkarıldı.
5. Modelin iyi-kötü olduğu nasıl değerlendirilir.
6. Her modelin somut uygulama adımları ve sonucun nasıl değerlendirildiği.

### Projeyle İlgili

1. Proje ekibinin yapısı ve ekibin içinde oynadığınız rol (projedeki sorumluluğunuz).
2. Projenin iş mimarisi (hangi modüller ve alt modüller) ve teknik mimarisi (mobil uç, PC ucu, arka uç teknoloji yığını).
3. Yazılım kontrol yönetimiyle ilgili araçlar (sürüm kontrolü, sorun yönetimi, sürekli entegrasyon).
4. Çekirdek iş varlıkları ve öznitelikleri, varlıklar arasındaki ilişkiler.
5. Hangi bağımlılık kütüphaneleri kullanıldı, bu kütüphaneler esas olarak hangi sorunları çözer.
6. Proje nasıl dağıtılıp yayına alınır ve projenin fiziksel mimarisi (Nginx, Gunicorn/uWSGI, Redis, MongoDB, MySQL, Supervisor vb.).
7. Proje nasıl test edilir, performans ayarı yapıldı mı.
8. Projede karşılaşılan zorluklar nelerdi, nasıl çözüldü.
