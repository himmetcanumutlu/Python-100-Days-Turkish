## Python ile MySQL Veritabanına Bağlanma

> **Translated to Turkish by** himmetcanumutlu

Python 3'te MySQL veritabanına bağlanıp veri kalıcılaştırma işlemi yapmak için `mysqlclient` veya `pymysql` üçüncü taraf kütüphanesini kullanabiliriz. İkisinin kullanımı tamamen aynıdır; yalnızca içe aktarılan modül adı farklıdır. Saf Python kütüphanesi olan `pymysql`'i kullanmanızı öneririz; çünkü kurulumu daha kolay başarılı olur. Aşağıda yine daha önce oluşturduğumuz `hrs` veritabanı örneğiyle, Python programıyla MySQL veritabanını işleyip veri kalıcılaştırmanın nasıl yapılacağını gösteriyoruz.

### MySQL'e Bağlanma

Önce komut satırında veya PyCharm'ın terminalinde aşağıdaki komutla `pymysql`'i kurabiliriz; MySQL 8'e bağlanmak gerekiyorsa, MySQL 8'in parola doğrulama biçimini desteklemek için `cryptography` adlı üçüncü taraf kütüphaneyi de kurmak gerekir.

```Shell
pip install pymysql cryptography
```

`pymysql` ile MySQL işlemenin adımları şunlardır:

1. Bağlantı oluşturma. MySQL sunucusu başlatıldıktan sonra TCP (Aktarım Kontrol Protokolü) tabanlı bir ağ hizmeti sunar. `pymysql` modülünün `connect` fonksiyonuyla MySQL sunucusuna bağlanabiliriz. `connect` fonksiyonunu çağırırken ana makine (`host`), port (`port`), kullanıcı adı (`user`), parola (`password`), veritabanı (`database`), karakter kümesi (`charset`) gibi parametreleri belirtmek gerekir; bu fonksiyon bir `Connection` nesnesi döndürür.
2. İmleç alma. MySQL sunucusuna başarıyla bağlandıktan sonra, sıradaki iş veritabanı sunucusuna SQL deyimi göndermektir; MySQL alınan SQL'i çalıştırıp sonucu ağ üzerinden döndürür. Bu işlemi yapmak için önce bağlantı nesnesinin `cursor` metoduyla imleç (`Cursor`) nesnesi alınır.
3. SQL gönderme. İmleç nesnesinin `execute` metoduyla veritabanına SQL deyimi gönderilebilir.
4. `insert`, `delete` veya `update` işlemi çalıştırılıyorsa, duruma göre işlemi onaylamak veya geri almak gerekir. Çünkü bağlantı oluşturulurken varsayılan olarak işlem ortamı açılır; işlem bittikten sonra bağlantı nesnesinin `commit` veya `rollback` metoduyla işlem onaylanır veya geri alınır; `rollback` metodu genellikle istisna yakalama bloğu `except` içine konur. `select` işlemi çalıştırılıyorsa, imleç nesnesiyle sorgu sonucu alınır; karşılık gelen üç metot vardır: `fetchone`, `fetchmany` ve `fetchall`. `fetchone` bir kaydı yakalayıp demet veya sözlük biçiminde döndürür; `fetchmany` ve `fetchall` birden çok kaydı yakalayıp iç içe demet veya sözlük listesi biçiminde döndürür.
5. Bağlantıyı kapatma. Kalıcılaştırma işlemi bittikten sonra bağlantıyı kapatıp dış kaynağı serbest bırakmayı unutmayın. Genellikle `finally` bloğunda bağlantı nesnesinin `close` metoduyla bağlantı kapatılır.

### Kod Uygulaması

Aşağıda kodla yukarıdaki beş adımı gösteriyoruz.

#### Veri Ekleme

```Python
import pymysql

no = int(input('Departman numarası: '))
name = input('Departman adı: ')
location = input('Departman konumu: ')

# 1. Bağlantı oluştur (Connection)
conn = pymysql.connect(host='127.0.0.1', port=3306,
                       user='guest', password='Guest.618',
                       database='hrs', charset='utf8mb4')
try:
    # 2. İmleç nesnesini al (Cursor)
    with conn.cursor() as cursor:
        # 3. İmleç nesnesiyle veritabanı sunucusuna SQL deyimi gönder
        affected_rows = cursor.execute(
            'insert into `tb_dept` values (%s, %s, %s)',
            (no, name, location)
        )
        if affected_rows == 1:
            print('Departman başarıyla eklendi!!!')
    # 4. İşlemi onayla (transaction)
    conn.commit()
except pymysql.MySQLError as err:
    # 4. İşlemi geri al
    conn.rollback()
    print(type(err), err)
finally:
    # 5. Bağlantıyı kapatıp kaynağı serbest bırak
    conn.close()
```

> **Not**: Yukarıdaki `127.0.0.1`'e geri döngü adresi denir; yerel makineyi temsil eder. Aşağıdaki `guest`, önceden oluşturduğum kullanıcıdır; bu kullanıcının `hrs` veritabanı üzerinde `insert`, `delete`, `update` ve `select` yetkileri vardır. Projede doğrudan `root` süper yönetici hesabıyla veritabanına erişmenizi önermiyoruz; bu çok tehlikelidir. Aşağıdaki komutla `guest` adlı kullanıcıyı oluşturup yetki verebiliriz.
>
> ```SQL
> create user 'guest'@'%' identified by 'Guest.618';
> grant insert, delete, update, select on `hrs`.* to 'guest'@'%';
> ```

Çok sayıda veri eklemek gerekirse, toplu işlem için imleç nesnesinin `executemany` metodunu kullanmanızı öneririz (bir `insert` işleminin arkasına birden çok veri grubu koymak); bir tabloya 10000 kayıt eklemeyi deneyip, toplu işlem kullanmadan tek tek eklemek ile toplu işlem kullanmanın farkını görebilirsiniz. İmleç nesnesinin `executemany` metodunun ilk parametresi yine SQL deyimidir; ikinci parametresi birden çok veri grubunu içeren liste veya demet olabilir.

#### Veri Silme

```Python
import pymysql

no = int(input('Departman numarası: '))

# 1. Bağlantı oluştur (Connection)
conn = pymysql.connect(host='127.0.0.1', port=3306,
                       user='guest', password='Guest.618',
                       database='hrs', charset='utf8mb4',
                       autocommit=True)
try:
    # 2. İmleç nesnesini al (Cursor)
    with conn.cursor() as cursor:
        # 3. İmleç nesnesiyle veritabanı sunucusuna SQL deyimi gönder
        affected_rows = cursor.execute(
            'delete from `tb_dept` where `dno`=%s',
            (no, )
        )
        if affected_rows == 1:
            print('Departman başarıyla silindi!!!')
finally:
    # 5. Bağlantıyı kapatıp kaynağı serbest bırak
    conn.close()
```

> **Not**: Her SQL işleminden sonra işlemi elle onaylamak veya geri almak istemiyorsanız, `connect` fonksiyonuna `autocommit` adlı bir parametre ekleyip değerini `True` yapabilirsiniz; bu, her SQL başarıyla çalıştıktan sonra otomatik onaylanması anlamına gelir. Yine de işlemi elle onaylamanızı veya geri almanızı öneririz; böylece gerçek iş ihtiyacına göre işlem ortamı kurulabilir. İstisna yakalayıp işlemek istemiyorsanız, `try` bloğundan sonra doğrudan `finally` bloğu koyabilirsiniz; `except`'i atlamak, istisna olduğunda kodun doğrudan çöküp istisna yığınını terminalde göstermesi anlamına gelir.

#### Veri Güncelleme

```Python
import pymysql

no = int(input('Departman numarası: '))
name = input('Departman adı: ')
location = input('Departman konumu: ')

# 1. Bağlantı oluştur (Connection)
conn = pymysql.connect(host='127.0.0.1', port=3306,
                       user='guest', password='Guest.618',
                       database='hrs', charset='utf8mb4')
try:
    # 2. İmleç nesnesini al (Cursor)
    with conn.cursor() as cursor:
        # 3. İmleç nesnesiyle veritabanı sunucusuna SQL deyimi gönder
        affected_rows = cursor.execute(
            'update `tb_dept` set `dname`=%s, `dloc`=%s where `dno`=%s',
            (name, location, no)
        )
        if affected_rows == 1:
            print('Departman bilgisi başarıyla güncellendi!!!')
    # 4. İşlemi onayla
    conn.commit()
except pymysql.MySQLError as err:
    # 4. İşlemi geri al
    conn.rollback()
    print(type(err), err)
finally:
    # 5. Bağlantıyı kapatıp kaynağı serbest bırak
    conn.close()
```

#### Veri Sorgulama

1. Departman tablosunun verisini sorgulama.

```Python
import pymysql

# 1. Bağlantı oluştur (Connection)
conn = pymysql.connect(host='127.0.0.1', port=3306,
                       user='guest', password='Guest.618',
                       database='hrs', charset='utf8mb4')
try:
    # 2. İmleç nesnesini al (Cursor)
    with conn.cursor() as cursor:
        # 3. İmleç nesnesiyle veritabanı sunucusuna SQL deyimi gönder
        cursor.execute('select `dno`, `dname`, `dloc` from `tb_dept`')
        # 4. İmleç nesnesiyle veriyi yakala
        row = cursor.fetchone()
        while row:
            print(row)
            row = cursor.fetchone()
except pymysql.MySQLError as err:
    print(type(err), err)
finally:
    # 5. Bağlantıyı kapatıp kaynağı serbest bırak
    conn.close()
```
>**Not**: Yukarıdaki kodda bir `while` döngüsü kurarak sorgu sonucunu satır satır yakalama işlemini gerçekleştirdik. Bu yaklaşım, özellikle sorgu sonucunun çok satırlı olduğu senaryolara uygundur. Çünkü `fetchall` ile tüm kayıtları tek seferde iç içe demete çekmek çok büyük bellek tüketimine yol açar; birçok senaryoda bu iyi bir fikir değildir. `while` döngüsü kullanmak istemiyorsanız, `iter` fonksiyonuyla bir yineleyici kurup veriyi satır satır çekmeyi de düşünebilirsiniz; merak edenler kendileri inceleyebilir.

2. Çalışan tablosunun verisini sayfalamalı sorgulama.

```Python
import pymysql

page = int(input('Sayfa numarası: '))
size = int(input('Boyut: '))

# 1. Bağlantı oluştur (Connection)
con = pymysql.connect(host='127.0.0.1', port=3306,
                      user='guest', password='Guest.618',
                      database='hrs', charset='utf8')
try:
    # 2. İmleç nesnesini al (Cursor)
    with con.cursor(pymysql.cursors.DictCursor) as cursor:
        # 3. İmleç nesnesiyle veritabanı sunucusuna SQL deyimi gönder
        cursor.execute(
            'select `eno`, `ename`, `job`, `sal` from `tb_emp` order by `sal` desc limit %s,%s',
            ((page - 1) * size, size)
        )
        # 4. İmleç nesnesiyle veriyi yakala
        for emp_dict in cursor.fetchall():
            print(emp_dict)
finally:
    # 5. Bağlantıyı kapatıp kaynağı serbest bırak
    con.close()
```

### Örnek Açıklaması

Aşağıda, veritabanı tablosundaki veriyi Excel dosyasına dışa aktaran bir örneği anlatıyoruz; önce `openpyxl` üçüncü taraf kütüphanesini kurmamız gerekir; komut aşağıdaki gibidir.

```Bash
pip install openpyxl
```

Şimdi aşağıdaki kodla `hrs` veritabanındaki tüm çalışanların numarası, adı, pozisyonu, aylık maaşı, primi ve departman adı bir Excel dosyasına aktarılır.

```Python
import openpyxl
import pymysql

# Çalışma kitabı nesnesi oluştur
workbook = openpyxl.Workbook()
# Varsayılan çalışma sayfasını al
sheet = workbook.active
# Çalışma sayfasının başlığını değiştir
sheet.title = 'Çalışan Temel Bilgileri'
# Çalışma sayfasına başlık ekle
sheet.append(('Sicil no', 'Ad', 'Pozisyon', 'Aylık maaş', 'Prim', 'Departman'))
# Bağlantı oluştur (Connection)
conn = pymysql.connect(host='127.0.0.1', port=3306,
                       user='guest', password='Guest.618',
                       database='hrs', charset='utf8mb4')
try:
    # İmleç nesnesini al (Cursor)
    with conn.cursor() as cursor:
        # İmleç nesnesiyle SQL deyimi çalıştır
        cursor.execute(
            'select `eno`, `ename`, `job`, `sal`, coalesce(`comm`, 0), `dname` '
            'from `tb_emp` natural join `tb_dept`'
        )
        # İmleçle veriyi yakala
        row = cursor.fetchone()
        while row:
            # Veriyi satır satır çalışma sayfasına yaz
            sheet.append(row)
            row = cursor.fetchone()
    # Çalışma kitabını kaydet
    workbook.save('hrs.xlsx')
except pymysql.MySQLError as err:
    print(err)
finally:
    # Bağlantıyı kapatıp kaynağı serbest bırak
    conn.close()
```

Yukarıdaki örneğe bakarak, Excel dosyasının verisini belirtilen veritabanının belirtilen tablosuna aktarmayı deneyip başarılı olup olmadığınıza bakabilirsiniz.
