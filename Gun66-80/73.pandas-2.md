#### CSV Dosyası Okuyup DataFrame Nesnesi Oluşturma

`pandas` modülünün `read_csv` fonksiyonuyla CSV dosyası okunabilir; `read_csv` fonksiyonunun parametreleri çoktur; aşağıda birkaç önemli parametreyi tanıtıyoruz.

- `sep` / `delimiter`: Ayraç, varsayılan `,`'dir.
- `header`: Başlığın (sütun indeksi) konumu, varsayılan `infer`; ilk satırın içeriği başlık (sütun indeksi) olarak kullanılır.
- `index_col`: Satır indeksi (etiket) olarak kullanılacak sütun.
- `usecols`: Yüklenecek sütunlar; sıra numarası veya sütun adı kullanılabilir.
- `true_values` / `false_values`: Hangi değerlerin `True` / `False` mantıksal değer sayılacağı.
- `skiprows`: Satır numarası, indeks veya fonksiyonla atlanacak satırları belirtir.
- `skipfooter`: Atlanacak sondaki satır sayısı.
- `nrows`: Okunacak satır sayısı.
- `na_values`: Hangi değerlerin boş değer sayılacağı.
- `iterator`: `True` yapılırsa fonksiyon yineleyici nesnesi döndürür.
- `chunksize`: Yukarıdaki parametreyle birlikte, her yinelemede alınacak veri miktarını ayarlar.

Kod:

```python
df3 = pd.read_csv('data/2018-beijing-puan-yerlestirme.csv', index_col='id')
df3
```

> **İpucu**: Yukarıdaki koddaki CSV dosyası göreli yolla alınır; yani mevcut çalışma yolunda `data` adlı klasör vardır ve CSV dosyası bu klasördedir. #### İlişkisel Veritabanı İki Boyutlu Tablosundan DataFrame Nesnesi Oluşturma

`pandas` modülünün `read_sql` fonksiyonu, SQL deyimiyle veritabanından veri okuyup `DataFrame` nesnesi oluşturur; fonksiyonun ikinci parametresi bağlanılacak veritabanını temsil eder. MySQL için `pymysql` veya `mysqlclient` ile veritabanı bağlantısı oluşturulur (üçüncü taraf kütüphane önceden kurulmalıdır); bir `Connection` nesnesi elde edilir; bu nesne `read_sql` fonksiyonunun ihtiyaç duyduğu ikinci parametredir; kod aşağıdaki gibidir.

Kod:

```python
import pymysql

# MySQL veritabanı bağlantı nesnesi oluştur
conn = pymysql.connect(
    host='101.42.16.8', port=3306,
    user='guest', password='Guest.618',
    database='hrs', charset='utf8mb4'
)
# SQL ile veritabanı iki boyutlu tablosundan veri okuyup DataFrame oluştur
df5 = pd.read_sql('select * from tb_emp', conn, index_col='eno')
df5
```

> **İpucu**: Yukarıdaki kodu çalıştırmak için önce `pymysql` kütüphanesini kurmak gerekir; kurulmadıysa hücrede önce `%pip install pymysql` sihirli komutunu çalıştırıp sonra yukarıdaki kodu çalıştırın. Yukarıdaki kod, Tencent Cloud'a dağıttığım MySQL veritabanına bağlanır; genel IP: `101.42.16.8`, kullanıcı adı: `guest`, parola: `Guest.618`, veritabanı: `hrs`, karakter kümesi: `utf8mb4`; bu veritabanını kullanabilirsiniz ama kötü niyetli erişim yapmayın. `hrs` veritabanında üç tablo vardır: `tb_dept` (departman tablosu), `tb_emp` (çalışan tablosu), `tb_emp2` (çalışan tablosu 2).

`SQLAlchemy`'nin `create_engine` fonksiyonuyla `Engine` nesnesi oluşturup `read_sql` fonksiyonunun ikinci parametresi olarak kullanın; bu durumda `read_sql` fonksiyonunun ilk parametresi SQL deyimi veya iki boyutlu tablonun adı olabilir.

```python
from sqlalchemy import create_engine

# Belirtilen URL (Tekdüzen Kaynak Bulucu) ile veritabanına eriş
engine = create_engine('mysql+pymysql://guest:Guest.618@101.42.16.8:3306/hrs')

df5 = pd.read_sql('tb_emp', engine, index_col='eno')
df5
```

### Veri İşleme

#### İndeks ve Dilim

`DataFrame`'in belirli bir sütununu almak istiyorsanız, örneğin `emp_df`'nin `ename` sütununu almak için aşağıdaki iki yöntem kullanılabilir.

```python
emp_df.ename
```

veya

```python
emp_df['ename']
```

Yukarıdaki kodu çalıştırınca bir `Series` nesnesi elde edildiği görülür. Aslında `DataFrame` nesnesi, birden çok `Series` nesnesinin bir araya gelmesidir.

`DataFrame`'in belirli bir satırını almak istiyorsanız tam sayı indeks veya belirlediğimiz indeks kullanılabilir; örneğin çalışan numarası `2056` olan çalışanın verisini almak için kod aşağıdaki gibidir.

```python
emp_df.iloc[1]
```

veya

```python
emp_df.loc[2056]
```

Yukarıdaki kodu çalıştırınca, `DataFrame`'in tek satırını veya tek sütununu almanın sonucunun `Series` nesnesi olduğunu görürüz. Elbette fancy indekslemeyle birden çok satır veya sütun verisi de alınabilir; fancy indekslemenin sonucu yine `DataFrame` nesnesidir.

Birden çok sütun alma:

```python
emp_df[['ename', 'job']]
```

Birden çok satır alma:

```python
emp_df.loc[[2056, 7800, 3344]]
```

`DataFrame` nesnesinin bir hücresinin verisini almak veya değiştirmek istiyorsanız, satır ve sütun indeksini birlikte belirtmek gerekir; örneğin çalışan numarası `2056` olan çalışanın pozisyon bilgisini almak için kod aşağıdaki gibidir.

```python
emp_df['job'][2056]
```

veya

```python
emp_df.loc[2056]['job']
```

veya

```python
emp_df.loc[2056, 'job']
```

Üçüncü yaklaşımı kullanmanızı öneririz; çünkü yalnızca bir kez indeks işlemi yapar. Bu çalışanın pozisyonunu "Mimar" olarak değiştirmek istiyorsanız aşağıdaki kodu kullanabilirsiniz.

```python
emp_df.loc[2056, 'job'] = 'Mimar'
```

Elbette dilim işlemiyle birden çok satır ve sütun da alınabilir; bunu düşünmüşsünüzdür.

```python
emp_df.loc[2056:3344]
```

#### Veri Filtreleme

Yukarıda fancy indekslemeden söz ettik; boolean indekslemeyi düşünmüşsünüzdür. `ndarray` ve `Series` gibi, boolean indekslemeyle `DataFrame` nesnesinde veri filtrelenebilir; örneğin `emp_df`'den aylık maaşı `3500`'ü aşan çalışanları filtreleyelim; kod aşağıdaki gibidir.

```python
emp_df[emp_df.sal > 3500]
```

Çıktı:

```

5566    Song Yuanqiao Muhasebeci      7800.0    4000    1000.0   10
7800    Zhang Sanfeng Genel Müdür        NaN      9000    1200.0    20
```

Elbette birden çok koşulu birleştirip veri filtreleyebiliriz; örneğin `emp_df`'den aylık maaşı `3500`'ü aşan ve departman numarası `20` olan çalışanları filtreleyelim; kod aşağıdaki gibidir.

```python
emp_df[(emp_df.sal > 3500) & (emp_df.dno == 20)]
```


Boolean indekslemeye ek olarak, `DataFrame` nesnesinin `query` metodu da veri filtreleyebilir; `query` metodunun parametresi bir string'dir; veri filtrelemede kullanılan ifadeyi temsil eder ve Python programcısının kullanım alışkanlığına daha uygundur. Aşağıda `query` metoduyla yukarıdaki etkiyi yeniden gerçekleyelim; kod aşağıdaki gibidir.

```python
emp_df.query('sal > 3500 and dno == 20')
```
